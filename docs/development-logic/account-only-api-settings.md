# Desktop 仅使用账号提供的 API 连接

Desktop 不再提供自填第三方 API Key 的功能，包括 Executor、Reviewer、摘要、文献检索和网络搜索的密钥输入、读取、清除及第三方连接测试。摘要模型使用账号 Executor 的连接，用户仍可选择账号内的摘要模型；独立 Reviewer 和审查方式保持独立。

## 配置约束

- `config_set` 和 `config_test` 拒绝旧客户端提交的密钥字段和外部模型连接，在写文件或发请求之前返回错误。保留旧字段的反序列化仅用于明确拒绝。
- 所有 Desktop 配置读取忽略历史第三方密钥；启动时在账号密钥迁移之后清理旧配置，每次保存再次清理，避免其他写入路径恢复旧密钥。第三方已验证连接也随之移除。
- 账号模型密钥继续使用系统凭据库和进程内存覆盖，不写入 `config.json`，也不通过 Reviewer 的进程环境导出。第三方密钥不会迁入凭据库。
- 不再从 Desktop 配置向搜索、文献工具导出第三方密钥；移除依赖环境密钥的 Desktop DeepSeek 预设。共享 CLI/runtime 的提供商能力保持兼容。
