# 子智能体摘要与侧栏对话

2026-10-15：子任务入口从主聊天顶部移到 Project Summary。普通子智能体仍使用共享控制器与原有独立 Session；正式 Reviewer 保持独立身份和原有审查流程。

摘要默认显示固定身份图标组与进行中的数量，失败和保存异常保持可见。点击进入 `agents` 类型的侧栏目录页签，列表显示可读名称、当前动作、真实状态和本轮执行用时；不再显示 `/root` 父子树和长任务说明。工具栏的摘要入口在打开侧栏时仍可使用。

身份图标的几何形状和颜色只由 canonical childSessionId 确定，在摘要、聊天委派提示、目录、子会话标题和页签中保持一致。状态使用独立标记，不改变身份。已知任务名和工具动作提供中英文显示，任意任务名保留可读回退，原路径和完整委派合约仍可查看。普通核查任务不会被标记成正式独立 Reviewer。

主聊天中，只有成功的 `spawn_agent` / `Agent` 工具结果与当前根会话下真实子任务的 sessionId 匹配时，才显示可点击委派提示。图标组打开目录，任务名称直接打开原子会话。失败、未返回、旧格式、未知或其他根会话的结果保留工具视图；混合结果维持原顺序。仅查看或点击入口不发起模型请求。

执行用时由 Tauri 从持久事件投影为 `startedAt` / `finishedAt`，前端只刷新显示。续派使用最近一轮开始时间，旧回合迟到的结束事件被忽略；停止或完成后冻结。旧记录缺少时间、异常退出没有明确结束时间，或检查点与事件尚未对齐时不显示推测用时；恢复不把进程停机时间算作执行。

点击子任务创建或聚焦 `agent` 类型的侧栏页签，使用稳定 childSessionId 读取原会话，提供“对话”“运行记录”和“追溯”视图。对话复用 ChatMessage 和主聊天的工具结果合并投影，以只读方式展示；任务详情、执行证据、停止及显式继续保留在侧栏。查询返回的结构化 turns 会过滤系统消息与私有 reasoning，并按现有证据规则脱敏；兼容没有 turns 的旧返回值。查看只读取检查点，打开、切换、关闭、恢复页签不会创建或启动子任务。

`useAgentTasks` 随主 Chat 持续订阅控制器快照与活动，摘要收起时也保留更新；列表状态按 revision 合并。侧栏按对应子任务事件刷新已保存的对话与时间线，合并短时间内事件，忽略切换后迟到的查询，不轮询文件或提交模型请求。模型生成中的正文会在 canonical 检查点保存后出现；当前执行状态和工具活动由事件更新，这不是逐 token 文本流。

页签描述与主任务侧栏状态一起保存在本地；恢复时验证 projectId 和根会话归属，后端再次验证 childSessionId 属于该父会话。正文不保存到侧栏偏好。关闭页签只关闭查看界面，停止使用原有控制器中断动作，继续使用原父会话显式续派。
