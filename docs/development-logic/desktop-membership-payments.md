# 桌面会员购买

桌面端在「设置 → 个人资料 → 购买会员」中展示当前账号的实时套餐报价，复用网页端支付宝电脑网站支付。选择套餐并勾选核对金额和用户服务协议后，客户端下单并在系统浏览器打开支付宝收银台，可扫码或使用支付宝付款。

购买规则与网页端一致：单次购买一个月，不自动续费；付款核验后起算，积分随本期到期失效。新购买不顺延已有套餐。

## 服务与身份

- `desktop/managed-newapi.json` 明确配对账号发行者 `https://somni.ensuanx.com` 和支付服务 `https://ensuanx.com`。支付地址来自构建配置，不接受前端传入目标服务器。回环开发账号和构建时覆盖的其他账号服务器不能将凭据发送给此生产支付服务；更换发行者时需要同时明确配置支付服务配对。
- `newapi::payments` 复用现有管理账号的续期机制。访问 `/v1/payments/alipay/quote`、`/order` 时在 Rust 中附加访问令牌和 `New-Api-User`，凭据不进入 WebView。
- 报价只接收完整的 Go、Plus、Pro 快照，核对账号 ID、金额、优惠规则、版本和积分。学生身份暂不可核对时沿用服务端公开报价，并在界面说明。
- 下单提交用户已核对的 `group`、`expectedRevision`、`expectedFen`、`priceKind`。服务端继续负责学生资格、价格版本、订单创建和履约；客户端不修改余额。

## 收银台与订单

返回的易支付订单必须属于当前账号，金额与确认金额一致，回调地址匹配账号服务器。表单仅 POST 到固定支付服务的 `/submit.php`，携带网站 Origin 和电脑设备标记，不携带账号凭据。Rust 禁止自动跟随重定向，只接收支付宝官方 `https://openapi.alipay.com/gateway.do` 的电脑网站支付 URL，再交给系统浏览器。

客户端创建订单期间锁定重复操作；浏览器打开失败时保留当前收银台，重试只打开已有订单。价格变更后须重新读取报价和确认。订单或收银台响应不明确时停止下单，先刷新服务端账户，再允许主动重新选择套餐。关闭购买面板和切换设置页保留当前订单；退出或切换账号后拒绝使用旧异步结果。

打开收银台或返回客户端均不代表支付成功。付款、回调验签、对账和权益发放继续由网页支付服务和 New API 负责。返回购买面板获得焦点或点击「刷新账户」时读取服务端账户，通过共享账号缓存更新会员、积分和可用模型。界面不依据浏览器回跳、余额猜测或前端状态显示支付成功。

## 验证

Rust 测试覆盖账户报价、优惠与金额、订单归属、回调地址、官方电脑收银台、停用支付、过期报价，以及模拟 HTTP 链路中的请求认证、无凭据表单提交和重定向边界。Vitest 覆盖个人资料入口、金额确认、重复点击、失败后重开已有收银台、账户刷新、价格变更、停用支付、订单不确定和退出登录期间的异步结果。
