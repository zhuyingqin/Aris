# 界面字号与屏幕适应

日期：2026-10-01

设置 → 通用 → 外观提供整体字体大小。默认选择自动适应；自定义范围为 12–20 px，步进 1 px。修改即时应用并存到本机，无需点击通用设置里的保存偏好。切回自动模式会保留上次自定义字号，方便再次选择。

## 自动推荐

`desktop/src/uiTypography.ts` 根据窗口内可用宽高与屏幕工作区宽高的较小值选择推荐字号。尺寸使用逻辑 CSS 像素，系统显示缩放已包含在尺寸中，不再乘 `devicePixelRatio`。只有两个方向都有足够空间时才增加字号，窄窗口和高度受限的超宽窗口保持 14 px。

| 最小可用宽度 | 最小可用高度 | 正文基准字号 |
| --- | --- | --- |
| 3200 | 1600 | 18 px |
| 2200 | 1200 | 16 px |
| 1600 | 900 | 15 px |
| 其他 | 其他 | 14 px |

`useUiTypography` 在窗口尺寸变化和重新聚焦时合并到一帧更新。自动模式更新实际字号；自定义模式只更新推荐提示。`storage` 事件同步其他同源工作区和伴随窗口里的偏好，每个窗口按自己的可用空间计算自动值。

## 全局缩放

现有界面包含大量固定像素字号及模块字体变量。Vite 接入 `uiTypographyPostcss`，将项目 `src` CSS 的字号、字体简写、固定行高和字体变量里的像素转成 `rem`。以 14 px 正文为默认基准，根元素字号设为 `16 × 当前字号 / 14`，保留标题、正文和辅助文字的原有层级，同时缩放侧栏、菜单、设置和各模块的界面文字。

初始偏好在 store 创建之前应用，避免首次绘制跳变。偏好键为 `somniq-ui-typography-v1`，包含 `mode` 和上次自定义的 `fontSize`。未显式选择时不写入默认偏好；无效存储回退到自动模式，字号限制在支持范围内。

转换只作用于字体相关声明。顶部窗口栏、项目工具栏和导航栏在 `AppChrome.css` 中显式使用 `rem` 设置栏高、图标、按钮及间距，让控件与文字同步缩放；项目名使用 13 px 标签基准，按钮及图标尺寸限制在适度范围内。停靠侧栏为产品切换器保留随字号增长的最小宽度，顶部与侧栏分界保持对齐。窗口变窄时顶部控件按可用空间换行，项目菜单按触发器的实际高度定位。

窗口栏的侧栏开关按导航栏实际宽度及边线居中，与左侧功能图标位于同一条竖线上；该对齐随字号与窄屏导航宽度同步变化。

其余布局尺寸、第三方样式和 PDF 文本层坐标保留原值；PDF、画布、终端及文档编辑器已有的内容字号与缩放参数保持各自的语义。新增界面字体规则可直接使用 `rem`，固定像素规则则自动经过同一转换。需要固定内容坐标的渲染样式应遵循现有 PDF 几何排除规则，或通过组件的内容缩放参数设置。

## 首页字体层级

`ChatHome.css` 在全局样式与 `AppChrome.css` 之后加载，使用统一的字体变量协调主工作区的首页、侧栏和输入区。默认 14px 设置下，首页主标题随聊天区宽度取 22–28px，产品入口 15px，输入文字 14px，卡片标题/说明/侧栏 13px，卡片提示 12px，徽章与辅助标签 11px。自定义字号与自动字号仍按全局比例应用。

首页标题字重为 650、卡片标题为 600。说明文字上限为 40rem；标题与说明平衡换行，卡片标签与徽章可换行。首页图标使用 56–80px 上限，小聊天区使用 56px；卡片图标、间距与留白使用 rem。短窗口可纵向滚动到全部入口。

输入区底部控件在空间不足时自动换行，右侧保持右对齐；合并的模型按钮根据实际可用空间收缩，完整型号与强度可从提示查看。验证见 `.somniq/changes/home-typography-2026-10-01/`：134 项定向测试、类型检查、最终生产构建、12 组首页布局和 4 组含权限及合并按钮的输入区检查通过；未重新打包原生客户端。

## 历史对话列表

历史标题沿用 13px 基准与 1.45 行高；置顶、项目内及远程对话使用相同的最小行高 `max(26px, 1.75rem)`。12/14/16/20px 字号设置下，行高分别约为 26/28/32/40px。内边距、项目缩进、文件夹图标、状态圆点和操作按钮按 rem 跟随文字变化；长标题保持单行省略，为右侧操作预留独立空间。大字号时可见条目减少，列表仍可滚动到最后一条。

重命名输入框使用与标题相同的字号及行高，并在行内居中，不再因原生输入框的基线和不同字号造成行高跳动。未读标题保留 600 字重，普通标题为 400；选中和运行状态保持原有提示。远程列表保留其网格布局，项目标题与普通分区标签分别设置内边距。

## 输入框与 Git 工具栏

Git 分支和变更数量并入输入框左侧工具栏，与权限及附件共用一行；右侧保留上下文、模型与思考入口和发送按钮。原有查看更改、分支切换、新建分支等操作仍由原来的回调处理。长分支名在预留的空间内省略，完整名称可从按钮提示查看；窄窗口按可用空间换行。Git 菜单根据触发器的实际位置限制横向位置和可用高度，字号或窗口变化时重新定位。

`ChatComposerLayout.css` 统一输入框的内边距、文字与工具栏间距，以及附件/发送按钮的尺寸。附件加号改用共享 `SvgIcon`，与其它图标采用同一套线条；按钮尺寸为 28–36px，图标为 14–20px，随字号适度变化。默认字号下，含 Git 状态的输入区总高度由约 150px 降至 102px；大字号和窄窗口保留必要的阅读与操作空间。

草稿在界面字号变化时重新计算高度；容器宽度变化时通过已有 ResizeObserver 更新文本框高度和聊天区域预留空间。长草稿超过原有高度上限后启用内部滚动，保留已输入内容。

## 顶部项目选择区

顶部项目区现在使用单个带文件夹图标、项目名称和箭头的入口，点击打开非模态项目面板。面板中的项目列表独立滚动，底部保留带文字的“添加本地项目…”和“打开项目文件夹”操作，避免顶部两个含义相近的图标并列。没有项目时入口仍可打开并添加目录；忙碌时项目及操作禁用。原有选择、拖动排序、目录选择、文件管理器打开及未保存内容确认仍由 App 的原有回调处理。

项目名称与面板操作采用 13px 基准、1.4 行高。顶部按钮高度为 26–36px，图标为 14–20px，名称按内容宽度显示，限制最大宽度并对超长名称使用省略号；完整名称和路径可从悬停提示查看。带图标入口的桌面最小宽度为 10.25rem、最大为 `min(14.25rem, 26vw)`，为图标预留空间并沿用此前名称的可读宽度；窄窗口取消最小宽度。面板按触发器实际位置限制高度，靠近窗口右侧时向左调整，字体或窗口变化时重新计算。方向键、Home/End 可移动项目焦点，Escape 关闭并返回入口，点击外部或 Tab 离开也可关闭。

根据较长名称的阅读需求，名称区后续适度放宽：桌面最小宽度为 9rem，最大为 `min(13rem, 24vw)`；窄窗口取消最小宽度，让名称继续随可用空间收缩。触发器的悬停提示包含完整项目名称和路径，超长名称仍采用省略号。14px 字号下短名称样例的整组宽度由 201px 调整为 241px；20px 字号下由约 278px 调整为 336px，高度沿用紧凑尺寸。
