# 模型选择旁的 DeepSeek 价格倍率

日期：2026-10-20。

聊天输入框当前模型、模型菜单选项、设置页 Executor / Reviewer 选择旁显示账号网关的相对价格。固定 `deepseek-v4.1-flash 高峰 = 1×`；低峰时 DeepSeek 显示 `0.5×`，其他费率未变的模型仍使用同一高峰基准。基准不可用时明确显示状态，不自动替换 DeepSeek 版本。模型选择仍提交原始 ID，Executor 与独立 Reviewer 的选择保持独立。

## 比较口径

```text
参考倍率 = (模型普通输入费率 + 模型输出费率)
         / (DeepSeek 高峰普通输入费率 + DeepSeek 高峰输出费率)
```

标签直接使用 `N×`，不显示约等号；DeepSeek 本身按当前价格与高峰价格之比显示 `1×` 或 `0.5×`。比较相同输入和输出 Token 数量（1:1），采用 1000 个输入 Token 的参考上下文，排除缓存命中。悬停可查看输入、输出、缓存的分别倍率、基准型号、当前档位、更新时间与过期缓存状态；这些细分倍率的分母也固定为高峰费率。它是选择模型时的参考，不是实际任务账单。

仅在确认输入、输出费率均为零时显示“免费”。按次计费模型按用户指定固定显示 `0.1`，悬停保留“按次计费”说明；该标签是显示约定，不参与 Token 价格倍率计算。不支持的表达式或特殊计费插件显示“阶梯计费”；缺价、账号分组不适用、无效费率及冲突条目显示“价格未知”。基准缺价或零价时不计算倍率。

## 网关实际计费

复用已登录会话访问 `/api/user/self` 与 `/api/pricing`，核实账号分组后计算有效费率。实际网关当前模型采用 `tiered_expr`；旧 `model_ratio` 字段不能覆盖表达式定价。

- `newapi/pricing.rs` 解析并返回安全的价格元数据，不向 WebView 传递凭据或完整账户响应。
- `newapi/pricing_expression.rs` 用有界的纯 Rust 解释器提取线性 Token 费率，支持 `p`、`c`、`cr`、`cc`，算术、布尔比较、条件分支、`tier()`、`fixed()`、`len`，以及上海和 UTC 的 `hour()` / `weekday()`。不执行脚本，未知或非线性规则不生成数值。
- DeepSeek 工作日上海时间 09:00–12:00、14:00–18:00 使用 `peak` 档，其他时段使用 `off_peak` 档。按读取时刻计算，相关目录在下一分钟失效，前端每 15 秒检查是否需刷新。
- `models` 保留当前计费档位；独立的 `peakBaseline` 保存固定 DeepSeek 高峰费率。对已支持的小时、星期表达式，以同一参考上下文遍历一周的小时，提取一致的 `peak` 价格。首次在低峰登录时即可识别高峰基准，不依赖历史高峰缓存，也不硬编码高峰单价。无法识别或高峰价格有冲突时不回退到低峰分母；恒定费率的基准在高峰也使用同一费率。
- 上下文条件以 1000 个输入 Token 求值，例如 GPT 的 `len <= 272000` 采用对应短上下文档；详情明确显示参考上下文及档位。
- 表达式未独立计价的缓存类别继承普通输入费率，保持 New API 的 Token 分类语义。旧比例定价将 `model_ratio` 乘以 2 后与表达式系数统一单位，并纳入账号分组倍率。
- LongCat 型号名称虽含 `free`，实际表达式为 `fixed(0.001)`，因此按次计费；按用户指定，选择器标签显示 `0.1`，详细计费类型可悬停查看。

此前真实已登录网关只读验证得到 15 条规范化模型价格。按 DeepSeek 高峰价计算，GPT 6.1 Sol 参考倍率为 `1.2×`，GPT 6 Astra 为 `6×`；DeepSeek 进入低峰档后，这两个倍率保持不变，DeepSeek 本身从 `1×` 变为 `0.5×`。这些数值来自账号费率快照，不作为固定报价写入应用。

## 状态与界面

`modelPricing.ts` 统一校验数据、计算倍率和中英文说明；`modelPricingState.ts` 与 `useModelPricing.ts` 为聊天和设置页共享同一请求及缓存。

- 缓存按网关、账号和分组隔离；账号切换丢弃旧请求结果，登出清除内存与本地缓存。
- 旧缓存缺少 `peakBaseline` 时直接失效并刷新，即使旧有效期尚未结束，也不能沿用按当前时段作分母的旧含义。
- 普通目录有效期最多 5 分钟，时段表达式按下一分钟边界失效；窗口重新聚焦与定时检查遵守有效期。手动同步模型会强制更新价格，后台模型列表同步复用缓存。
- 失败保留已确认价格并标记缓存状态；无可用缓存时显示“价格暂不可用”。重试间隔 30 秒，多个使用方合并请求。
- `ChatComposer.tsx` 在当前模型和各选项右侧展示倍率标签，菜单不显示额外的计价基准段落；悬停说明可查看比较细节。`ModelsSettings.tsx` 在独立设置页中展示两个角色的价格及计价口径。
- Chat 首页不挂载模型服务、Somni 绘图和辅助模型等设置内容。验证脚本默认只渲染 Chat 输入框与模型菜单，设置页使用独立的 `?view=settings` 视图，避免把并排组件验证误认为产品布局。
- 所有分类统一显示名称、数量及展开按钮，只有一个模型时也放在分类内。打开菜单时自动展开当前模型所属分类，切换分类会折叠其他分类，展开后显示模型及价格标签。
- 同一分类内按倍率数值从低到高排序，免费视为 `0`、按次标签按 `0.1` 排列，未确认价格放在组尾。同倍率保留目录顺序，分类自身仍按目录顺序；排序使用未舍入的数值，价格加载或刷新后同步更新，不改变当前选中模型。
- 选中模型仅保留原有高亮，价格标签旁不显示勾选图标；保留 `aria-checked` 以标明选中状态。
- Chat 和设置页共用 `modelPricing.css` 的倍率胶囊样式：柔和的主题配色、细边框、等宽数字和统一最小宽度，选中模型的标签适度加强颜色；按次 `0.1` 使用同一样式，未确认价格保持中性颜色。
- 远程节点聊天不显示本机账户价格，需要远端提供价格信息后才可比较。
