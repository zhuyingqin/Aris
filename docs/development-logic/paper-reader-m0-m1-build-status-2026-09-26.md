## 已接入的使用路径

在文献库选中有本地 PDF 的论文，在阅读器中点击“多模态论文解析”。前端准备整篇原始页图和可用的嵌入文本，后台随后自动逐页派发 Somni Chat 任务，再生成论文主线及关键主题讲解。用户无需选公式或逐页确认。右侧默认展示结合原图的解释、分步说明、例子和理解检查，左侧保留可跳转的 PDF。

结果按页保存文本、公式、图片和表格的候选内容、识别疑点及来源。可以取消、继续未完成的任务、重试失败页，并从结果跳到原 PDF 对应页。页面准备依赖当前阅读器；准备时关闭阅读器会中止准备，下次可以继续。全部原页准备完成并派发后台任务后，关闭阅读器不停止后台解析。

页面处理覆盖、已识别候选清单和识别完整性分别展示。识别完整性始终为“未验证”，内容始终为“尚未独立审核”。原有页级记录的 `page_processing_complete` 可以继续生成讲解；新增任务只有页处理和全部选定主题都完成才产生 `guide_ready`，其含义仅为草稿已生成。

## 执行与存储边界

| 位置 | 本批职责 |
| --- | --- |
| `desktop/src/literature/PaperReadingPanel.tsx` | 主按钮、页面准备、事件订阅、状态与页级跳转；不调度模型轮次 |
| `desktop/src-tauri/src/paper_reading.rs` | 校验文献与 PDF、保护原始材料、领取运行权、派发下一页、取消与任务事件 |
| `desktop/src-tauri/src/engine.rs` | `PaperReading` 上下文进入现有 `run_chat_turn_with_context`，复用 Chat 模型、富消息、会话、用量、追踪与取消 |
| `crates/runtime/src/paper_reading.rs` | 页级状态机、严格产物协议、覆盖维度、尝试记录和带版本条件的保存 |

每次尝试使用独立的 Chat 会话，直接携带原页图像与辅助原文。没有其他聊天历史、项目研究记忆或执行器审查记忆注入；工具列表为空，工具执行入口再次拒绝所有调用，不加载项目 MCP／hooks。调度由 Rust 领域状态和桌面宿主推进，模型没有调度权。

任务绑定项目、文献、PDF SHA-256、模型、非敏感连接配置签名、语言和协议版本。连接签名包含协议类型、端点和传输选择，不包含密钥。执行前再次核对配置；变更后不把旧连接的结果写入当前任务。原图、辅助文本和原文版本在任务内保持不可变。并发保存不会覆盖已经绑定的原图；取消后的旧版本提交被拒绝。

SQLite 文献库模式升级至 8，新增 `paper_reading_runs`。原始 PDF 快照和页图保存在项目的 `.somniq/literature/artifacts/paper-reading/<run-id>/`；模型会话使用现有 Chat 的项目会话存储，页级尝试记录关联其会话 ID。恢复时保留历史尝试，跳过已成功保存的页。

本批边界：PDF ≤64 MiB、1–500 页、单页 JPEG ≤8 MiB、每任务页图 ≤256 MiB、每页最多 3 次尝试。页任务串行，每次 Chat 尝试最多 2 次模型迭代、设置 180 秒轮次预算；请求传输仍沿用共享执行器的超时与取消机制。崩溃前已发送但未保存的请求可能在继续时重发，不承诺模型费用恰好一次。
