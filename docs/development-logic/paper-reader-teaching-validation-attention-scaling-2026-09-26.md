**局部理解结构与预期讲解。**

局部骨架只需说明这个操作位于注意力计算内部，连接“匹配分数 → 权重 → 对 V 加权求和”。核心主张是论文采用 √dₖ 缩放；教学要补足的缺口是为什么该尺度与方差有关，以及为何不能推断“分数数值大就必然饱和”。来源绑定 E1–E4，不要求先生成全篇 Skeleton 或通用 Reasoning Model。

参考直觉：点积会累加多个维度的贡献。在特定随机变量假设下，维度增加会放大分数的波动尺度，softmax 更容易给出集中的权重。按 √dₖ 缩放用于控制这一尺度。这里关注分数之间的差异，给所有分数加同一个常数不会改变 softmax；缩放也不保证每个实际样本的梯度都更大。这些限定用于教学，不能省略。

计算对象的形状明确为：Q 是 n_q × dₖ，K 是 n_k × dₖ，V 是 n_k × dᵥ；QKᵀ 是 n_q × n_k。每个 query 对全部 key 的分数做一次 softmax，所得权重用于组合对应的 V，输出形状为 n_q × dᵥ。

**数学推导参考：逐步说明假设的用途。**

以下是基于 E3 假设展开的教学推导；公式中每一步的依据需要在实际生成产物中保留。

令 q、k 的所有分量相互独立，均值为 0、方差为 1，dₖ 为正整数。这里只需相应独立性与二阶矩条件，不要求分量服从正态分布。令 Zᵢ = qᵢkᵢ，S = ∑ᵢ Zᵢ。

| 步骤 | 结论 | 依据 |
| --- | --- | --- |
| 1 | E[Zᵢ] = E[qᵢ]E[kᵢ] = 0 | qᵢ 与 kᵢ 独立、零均值 |
| 2 | E[Zᵢ²] = E[qᵢ²]E[kᵢ²] = 1 | 独立，且零均值、单位方差意味着二阶矩为 1 |
| 3 | Var(Zᵢ) = E[Zᵢ²] − E[Zᵢ]² = 1 | 方差定义 |
| 4 | Var(S) = ∑ᵢ Var(Zᵢ) = dₖ | 不同分量对之间独立，交叉协方差为 0 |
| 5 | Var(S / √dₖ) = Var(S) / dₖ = 1 | Var(aX) = a²Var(X) |
| 6 | 若改为 S / dₖ，则 Var(S / dₖ) = 1 / dₖ | 同一方差缩放规则 |

因此 √dₖ 对应这个假设下的标准差尺度。训练后的 Q、K 未必满足这些假设，不能把第 5 步说成任意注意力分数的经验事实，也不能据此保证训练收敛。

补充检查：softmax 分量 sᵢ 对输入 zⱼ 的导数为 sᵢ(δᵢⱼ − sⱼ)。当权重高度集中时，这些导数可能很小。但 softmax([100, 100]) 与 softmax([0, 0]) 都是 [0.5, 0.5]，说明单看绝对数值不能判定饱和。比较对未缩放点积的导数时，还须计入缩放的链式法则，不能仅凭某个 softmax 导数变大就宣称整个网络梯度变大。

**数值示例参考：构造例子，不是论文实验。**

取一个 query、两个 key，dₖ = 4、dᵥ = 2：

- q = [1, 1, 1, 1]。
- k₁ = [1, 1, 1, 1]，k₂ = [1, 1, 1, −1]。
- v₁ = [2, 0]，v₂ = [0, 2]。

点积是 [4, 2]，按 √4 缩放后是 [2, 1]。softmax([a, b]) 的第一项为 exp(a) / (exp(a) + exp(b))，第二项为 1 减第一项。

| 步骤 | 未缩放 | 采用 √dₖ 缩放 |
| --- | --- | --- |
| 送入 softmax 的分数 | [4, 2] | [2, 1] |
| 注意力权重 | [0.880797078, 0.119202922] | [0.731058579, 0.268941421] |
| 对 V 加权求和 | [1.761594156, 0.238405844] | [1.462117157, 0.537882843] |

若错误地除以 dₖ，分数会成为 [1, 0.5]，权重约为 [0.622459331, 0.377540669]；这可作为可计算的错误对照。上述数值已用 JavaScript 核对，验证时允许绝对误差 10⁻⁶。

本例展示分数、权重和输出之间的关系；给定的几个整数不能用来验证随机变量的方差假设。较平缓的权重也不等同于实际任务效果一定更好。

可复算代码只用于这个固定样例：

```javascript
const q = [1, 1, 1, 1];
const keys = [[1, 1, 1, 1], [1, 1, 1, -1]];
const values = [[2, 0], [0, 2]];
const dot = (a, b) => a.reduce((sum, x, i) => sum + x * b[i], 0);
const softmax = (xs) => {
  const m = Math.max(...xs);
  const exps = xs.map(x => Math.exp(x - m));
  const total = exps.reduce((sum, x) => sum + x, 0);
  return exps.map(x => x / total);
};
const scores = keys.map(k => dot(q, k));
for (const divisor of [1, Math.sqrt(q.length), q.length]) {
  const weights = softmax(scores.map(x => x / divisor));
  const output = values[0].map((_, j) =>
    weights.reduce((sum, w, i) => sum + w * values[i][j], 0));
  console.log({ divisor, weights, output });
}
```
