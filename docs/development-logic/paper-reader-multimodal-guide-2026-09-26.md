# 文献库图文讲解构建与实测

日期：2026-09-26。用户指出仅有 PDF 页级识别没有实现“让读者理解论文”。本轮把面向读者的讲解接入文献库，并实际调用 Somni Chat 生成结果。Reviewer 按用户要求继续暂停。

## 产品交付

在文献库打开 PDF，点击“多模态论文解析”，后台自动推进：全文原页识别 → 论文主线 → 关键主题讲解。用户不必选公式或逐页启动。已有页级结果可以点击“生成论文讲解”，复用已保存的原页材料。

阅读器左侧保留 PDF，右侧默认显示图文讲解：

- 论文主线：研究问题、方法思路、实验依据和结论边界。
- 按方法图、关键公式、实验与概念组织的主题；点击主题跳到相应原页。
- 原页缩略图、直觉说明、符号与图示说明、适用前提、分步解释、教学例子和理解检查。
- “原文说明”与“讲解补充”分别标注；参考答案可展开，原文可回查。
- 页级转写放入“原文识别”标签，处理覆盖放入“处理记录”。生成内容标为未独立审核的草稿。

这是一版结合原图与数学排版的阅读辅助。尚未实现图中区域高亮、可操纵的推演图、通用 Reasoning Model、按实际掌握情况更新的 Reader Model，或独立审核／修订循环。讲解先按具备机器学习基础的读者组织，不把固定读者设定叫作 Reader Model。

## 执行边界

沿用 `paper_reading_start → run_paper_reading_turn → run_chat_turn_with_context`。理解主线和每个讲解主题都使用独立、无工具的 Somni Chat 任务；宿主负责顺序调度、取消、持久化与重试，模型不决定调度。不新增直接模型 HTTP 调用路径，也不把 Executor 的自检标为独立 Reviewer。

主线任务取得原 PDF 文本（总预算 120,000 字符、每页最多 30,000 字符）与最多 8 张原页图。页级候选类型仅用于查找原页，感知草稿的正文不作为原文传递。每个主题最多请求 4 页，讲解时重新读取这些页的原图与原始文本；校验图像哈希，记录实际交付的页号、图像／文本哈希和截断状态。图像总预算 32 MiB；教学原图超过预算会报错，不静默退化成只读草稿。

新增 `PaperGuide` 状态保存主线、主题、内容、尝试和材料交付记录。严格校验 JSON 类型、字段、篇幅及来源页；非法输出保留失败记录。每项最多 3 次尝试，重试跳过成功主题；取消后迟到结果不能提交。旧页级记录无需重跑识别便可补上讲解。

状态区分：页处理完成不代表讲解完成；`guide_ready` 仅表示所有页处理和选定主题草稿生成完成。识别完整性仍为 `not_checked`，审核仍为 `not_reviewed`，不以任务状态宣称知识正确。

## 真实模型运行

沿用先前实测的《Attention Is All You Need》v7 原 PDF，共 15 页。模型为当前 Somni 配置的 MiniMax-M3。复用已完成的 15 页识别；第 4、8、9 页仍只有图像、没有辅助文本。未向模型提供 T0 的人工参考答案。

| 运行 | 新页级调用 | 新讲解调用 | 结果 | 耗时 |
| --- | --- | --- | --- | --- |
| 首次补充讲解 | 0 | 7（1 个主线、6 个主题） | 主线及 4 个主题完成，2 个主题 JSON 类型错误 | 409.659 秒 |
| 强化类型与内容约束后的重试 | 0 | 2 | 两个失败主题恢复，6 个主题全部保存 | 183.731 秒 |
| 重启恢复 | 0 | 0 | 原任务恢复，保存前后内容一致 | 2.337 秒 |

生成主题覆盖整体架构、缩放点积、多头注意力、位置编码、Table 2 翻译实验和 Table 1 理论复杂度。主线输入原图页号为 3、4、5、6、8、9、10、13；六个主题分别读入原图 `[3]`、`[4]`、`[4,5]`、`[6,9]`、`[8]`、`[6]`。9 次实际模型请求全部包含图像、工具列表为空；用量角色全部是 Executor，共 50,581 输入 tokens、41,342 输出 tokens。费用未计价。

首次失败来自模型将 `notation` 返回成对象、`assumptions` 返回成数组，未符合 Markdown 字符串协议。明确类型和一次 JSON 转义要求后，两项重试成功；未通过宽松解析把非法结果直接算作成功。

## 阅读质量抽查：尚未通过教学质量验收

讲解比页级转写增加了原图流程说明、变量维度、分步论证与问题，但结构化成功不等于解释准确。以下是开发时人工对照原页及 T0 基准的抽查，不会赋予独立审核状态。

| 内容 | 有用部分 | 仍存在的问题 |
| --- | --- | --- |
| 整体架构 | 编码器／解码器、残差、位置编码与输出流程可对应 Figure 1 | 把置换等变称为置换不变；示例对遮罩对角线的说明有误，并越出所读页推断共享权重 |
| 缩放点积核心难点 | 公式、矩阵形状、独立／零均值／单位方差假设，以及方差展开已生成 | 直觉和答案仍将控制方差扩写为“保证训练稳定”；对 softmax 集中的解释不充分，与自己的谨慎说明矛盾。T0 内容未通过 |
| 多头与位置编码 | 原图投影／拼接流程、位置编码旋转关系提供可读解释 | 部分公式仍是未包数学分隔符的纯文本；位置编码自测答案对位置 0 的解释错误 |
| 实验与复杂度表 | 主要 BLEU 与表格比较框架可帮助回查 | Table 2 合并成本格的列归属仍错；复杂度说明把卷积层路径的不同条件混在一起，并有过度比较 |

修改提示词后，类型错误得到修复，但上述语义问题没有被可靠消除。本轮不宣称完整 T0、真实读者学习效果或模型事实准确率达标；Reviewer 仍未接入。后续先改善原图局部取证、表格结构对应和关键难点的限定条件，再进行目标读者试读；不以新增模块代替这些内容验证。

## 工程与界面验证

- Rust 工作区 1,209 个测试通过，5 个既有忽略项；包含 5 个新增讲解状态／协议测试。
- Tauri 论文任务聚焦测试 7 个通过，包含“错误感知草稿不能替代原始教学输入”。
- 阅读器相关 Vitest 共 107 个不同测试通过；最后的展示调整后重跑对应组件测试。TypeScript 检查和前端构建通过。
- 使用真实已保存的模型产物回放实际 `PdfReader`／`PaperReadingPanel` 组件，校验 6 个主题、原页画布、跳转至 PDF 第 4 页及自测答案展开。1440 与 720 像素窗口没有页面横向溢出，无脚本错误。
- 六个主题现有数学片段共 232 个，未出现 KaTeX 报错；这不验证公式的语义，也不将未加分隔符的纯文本公式计入渲染成功。
- UI 回放是只读本地夹具，不发模型请求；实际模型运行由隔离的桌面诊断宿主执行。本轮没有完成已安装桌面应用中的人工全流程点击，也没有目标读者试读。
