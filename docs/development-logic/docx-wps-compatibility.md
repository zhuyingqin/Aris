# DOCX 修复与 WPS 兼容性记录

2026-11-11：原 13 项原生工具缺口已在公开文件和 LibreOffice PDF 验收中关闭。新候选尚未在 WPS 复测，WPS 兼容性仍未确认。用户要求直接 PDF 截图后，本轮没有进行电脑界面操作。

本轮修复明确空段落及段落标记的字号、行距和网格控制，字体样例在 LibreOffice 中保持 3 页且无白尾页；这不构成 WPS 修复完成的证据。原生字段和 OMML 的结构保留也不证明 WPS 可编辑性。完整结果见 [公开任务验收](docx-public-acceptance.md)。

## 修复前 WPS 事实

旧候选在 WPS 12.1.0.29690 完成字体样例的打开、独立另存 DOCX 和 PDF 导出；WPS PDF 为 4 页，第 4 页逐像素纯白，LibreOffice PDF 为 3 页。旧 WPS 第 2 页只有时间线表头，首条记录移到第 3 页。文字、表格及显式分页数量保持，但该次分页验收失败。

历史 12 页已由 Executor 查看，其中 WPS 4 页、LibreOffice 8 页。这些旧结果保留，不绑定到本轮新候选。字体样例没有图片或公式，不能推断 WPS 的图片/公式编辑能力；关闭重开未完成，其他四例未做 WPS 导出。

## 证据与完成条件

[机器清单](docx-wps-compatibility.json) 区分当前原生修复与历史 WPS 证据。历史文件位于 `.somniq/research/wps-compatibility-20261111/`，含 `pdf-inspection.json`、`page-observations.json`、`font/wps-saved.docx` 和 `font/wps-saved.pdf`；输入、保存、截图与 PDF 哈希保留。本轮证据位于 `.somniq/research/docx-native-repair-20261111/`。旧目录的发布脚本只对应历史状态，不应用于新报告。

目标编辑器兼容通过需要新候选的 DOCX/PDF 版本绑定、逐页查看、约定页数、正文/表格保留，以及实际保存重开；原生公式须另验可编辑性。目前这些 WPS 条件未满足，Word 和旧二进制 `.doc` 同样未验证。Open XML SDK 对本轮 19 份 DOCX 的检查无新增结构错误，但不能替代目标编辑器验收。
