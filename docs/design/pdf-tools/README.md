# 文献库 PDF 工具重设计

2026-09-30：按用户提供的参考图及后续反馈，直接更新桌面应用的 React PDF 阅读组件。

当前工具栏为 60px 宽的竖向圆角栏。顶部显示 PDF，当前页与总页数在同一行显示，例如 `2 / 15`，当前页仍可编辑跳转。页码下方直接显示上一页、下一页箭头，无需打开更多浮层。首次或末次页组会禁用对应按钮，双页/四页布局按页组翻页。下面依次为放大、缩小、整页适配、论文讲解、系统阅读器和更多工具。PDF 标题区域支持拖动、双击复位及键盘移动。阅读背景保留参考图的灰色衬底；用户截图中的红框仅用于指出工具区域。

更多浮层保留单页/双页/四页布局、缩放比例、宽度适配、标注、刷新，以及调用方提供的文件定位操作。浮层按剩余空间向左或向右展开，位置限制在 PDF 可视区域内。Escape 关闭后恢复焦点，点击外部关闭；打开讲解、改变浮层状态和移动工具条均保留阅读状态。矮窗口中工具栏可以滚动，PDF 标题和拖动入口固定在顶部。

截图来自实际应用组件的本地 Vite 浏览器预览。PDF.js 渲染已有的本地《Attention Is All You Need》PDF；文献元数据使用隔离的浏览器样例，原生 IPC 由截图脚本替代，没有调用模型或读取用户的正式文献库。这次未做打包 Tauri 窗口验收。

本次页码同行排版通过 PDF 阅读器与样式聚焦测试和桌面生产构建。此前翻页入口修正通过 58 项聚焦测试及 TypeScript 检查，参考样式改版通过文献库的 96 项交互测试。构建仍有既有的分包体积和混合导入提示。

[浏览器检查记录](inline-pages-browser-checks.json)覆盖四种窗口/主题/语言组合，验证当前页与总页数在同一行且不溢出、更多浮层关闭时翻页按钮可见、点击及 Enter 翻页、首页禁用上一页、双页/四页按页组翻页，以及工具条宽度、页码间距、文字溢出、布局与缩放保持、浮层边界翻转、键盘移动边界和讲解关闭后的焦点恢复。交互期间没有重复加载 PDF 或启动模型生成。记录单独保留了注入 IPC 前的浏览器原生截图监听警告；注入后阅读器检查没有运行时错误。

复现：从 `desktop/` 运行 Vite 于 `127.0.0.1:1421`，再运行 `node .audit/pdf-tools-inline-pages-preview.cjs`。最终报告和执行日志位于 `desktop/.audit/pdf-tools-inline-pages-*`。此前分组面板、参考样式首版和纵向页码版的截图及检查报告保留为设计历史，当前产品使用上述页码同行显示且带翻页箭头的窄竖条。
