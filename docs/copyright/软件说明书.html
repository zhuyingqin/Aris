第一章　软件概述

1.1　软件简介

应算科研工作台软件（SomniQ Studio，以下简称"本软件"）是一款面向高等院校与科研院所研究人员的本地优先桌面应用软件。本软件以"研究项目"为基本组织单元，将研究目标、文献证据、实验数据、计算过程、代码实现、论文写作与结论审查等科研活动的各个环节，组织在同一个可持续、可追溯的工作上下文之中。

与以单轮问答为交互模型的通用对话软件不同，本软件的设计出发点是科研工作本身的连续性：一项研究的目标、当前进展与历史决策，不会因为某一次对话的结束而丢失；研究过程中产生的文献、数据、实验结果与写作内容，共同构成一条可以被逐项检查的证据链。

本软件在单一桌面程序内集成了研究对话、实验计算、学术排版、文献管理、知识管理、代码编辑、邮件处理、任务编排与系统配置等九类功能，用户无需在多个独立工具之间反复切换并重复交代研究背景。

1.2　设计目标与解决的问题

本软件针对科研工作中长期存在的以下四类问题进行设计：

  • 上下文反复丢失。研究者在使用通用辅助工具时，每开启一次新的交互都需要重新交代研究背景、已有进展与约束条件，时间成本高且容易遗漏关键前提。本软件将研究目标、里程碑与历史决策作为长期状态持久保存于本地。
  • 工具割裂。文献检索、实验执行、数据分析、论文排版分别依赖不同的软件，中间产物在工具之间以文件形式手工搬运，易产生版本不一致。本软件将上述环节纳入同一工作台并共享同一份项目数据。
  • 结论缺乏交叉校验。自动生成的研究结论若无独立环节加以质疑，容易出现证据不足却表述肯定的情况。本软件引入独立审查角色，对方法、证据与论证进行独立质疑，并将审查意见回流至执行环节形成修订循环。
  • 数据不可控。研究数据涉及未发表成果，上传至外部服务存在泄露风险。本软件采用本地优先架构，项目数据全部落盘于用户本机。

1.3　体系结构

本软件采用"一个内核、多个外壳"的分层架构。全部代理执行逻辑、工具注册表与会话数据格式集中实现于共享内核层，桌面端界面与移动远程端仅作为同一内核之上的不同产品表面，任一外壳不调用另一外壳的进程，从根本上避免多端逻辑重复实现与行为漂移。

层次组成与职责
产品外壳层桌面端（跨平台桌面应用框架 + 前端界面 + 本地后端服务）；移动远程端（渐进式网页应用 + 自托管网关，经端到端加密协议访问桌面端）
共享内核层运行时（会话循环、权限控制、上下文压缩、分层记忆、外部工具协议）；模型接入与执行（双协议流式接入）；装配层；工具集（约五十个科研工具）；计算内核客户端；远程加密协议
技能层七十余个内置科研流程技能，覆盖文献调研、想法发现、实验执行、独立审查、论文写作与投稿重投
本地数据层配置、会话记录、运行状态、文献库、知识库、用量日志，全部存储于用户本机磁盘

1.5　技术特点

  1. 单内核多外壳架构。代理逻辑、工具注册表与会话格式统一实现，桌面端与远程端共享同一套运行时，消除多端行为漂移。
  2. 双模型独立审查闭环。执行角色模型推进研究工作，审查角色模型以独立身份质疑方法、证据与论证；审查意见回流至执行阶段形成修订循环，直至满足预设质量门限，而非在首版答案处终止。
  3. 上下文保真压缩机制。采用固定上下文与递归归并相结合的压缩策略，配合确定性的覆盖度校验门禁，在长会话中避免因前缀丢弃导致的信息断裂。
  4. 本地优先的数据自治。研究项目的目标、证据、会话、文献与知识全部落盘本地，仅在用户显式配置模型服务或远程网关时与外部通信。
  5. 端到端加密的远程控制协议。以版本化加密协议原语支撑移动端经自托管网关远程操作桌面端，会话授权按单次匹配的会话标识范围最小化。
  6. 可回滚的编辑历史机制。以影子版本库作为单一事实来源，建立编辑器撤销、文件快照与会话轮次三层回滚模型，三层共享同一提交池。
  7. 双协议模型接入层。同时支持两类主流大模型服务协议的流式接入，具备传输方式三态选择与运行时能力降级。
  8. 可插拔技能体系。技能以声明式文档定义，内置七十余个科研流程技能并支持第三方扩展。

2.3　安装步骤

  1. 获取安装程序。安装文件为 Windows 可执行安装包，文件名形如"软件名_版本号_x64-setup.exe"。
  2. 双击安装程序。若操作系统提示用户账户控制确认，选择"是"以允许安装程序运行。
  3. 在安装向导中阅读许可协议，确认后点击"下一步"。
  4. 选择安装目录。默认安装至当前用户的本地应用程序目录，建议保持默认；若需更改，请选择可用空间不少于 2GB 的磁盘分区。
  5. 点击"安装"开始复制文件。若系统缺少界面渲染运行时，安装程序将自动下载并部署该组件，此步骤需要网络连接。
  6. 安装完成后点击"完成"。安装程序会在开始菜单与桌面创建快捷方式。

2.4　首次启动与初始化配置

首次启动时，本软件会引导用户完成账户登录与模型服务配置。未完成模型服务配置时，除研究对话之外的本地功能（文献库浏览、笔记本编辑、排版编译等）仍可正常使用。

  1. 双击桌面快捷方式启动本软件，等待主窗口出现。
  2. 在登录界面输入账户凭据完成登录；若使用自建模型服务网关，可在此处填写网关地址。
  3. 登录后软件进入主界面，并自动展示新手引导。引导逐一介绍各功能标签页的用途，可随时关闭。
  4. 点击左侧导航栏底部的"设置"进入系统设置，在"模型"分区中确认可用模型列表已正确加载。
  5. 在"模型"分区中分别为执行角色与审查角色指定模型。执行角色负责推进研究工作，审查角色负责独立质疑，二者应选择不同来源的模型以保证审查独立性。
  6. 在"系统"分区中运行环境检测，确认可选组件（计算内核、版本管理工具）的可用状态。

2.5　升级与卸载

2.5.1　升级

本软件内置更新检查功能。当检测到新版本时，界面会给出更新提示。用户确认后软件将下载更新包并在下次启动时完成安装。升级过程不会影响本地已有的会话记录、文献库与配置数据。用户也可在"设置—关于"分区中手动触发更新检查。

2.5.2　卸载

  1. 打开操作系统的"设置—应用—已安装的应用"。
  2. 在列表中找到本软件条目，点击"卸载"。
  3. 按提示确认后，卸载程序将移除程序文件与快捷方式。
  4. 卸载程序不会删除用户数据目录中的会话记录、文献库与配置文件。如需彻底清除，请在卸载完成后手动删除用户配置目录（路径可在"设置—关于"分区中查看）。

提示：卸载前建议先对用户数据目录进行备份，详见第 14.5 节。

第三章　界面总览与基本操作

3.1　主窗口布局

本软件主窗口采用无系统边框设计，整体分为三个区域：顶部标题栏、左侧功能导航栏与右侧内容区。

  • 顶部标题栏。左侧显示当前项目名称与软件标识，右侧为窗口控制按钮（最小化、最大化、关闭）。标题栏区域支持拖拽移动窗口，双击可在最大化与还原之间切换。
  • 左侧功能导航栏。纵向排列各功能模块入口，点击图标切换至对应模块。导航栏可折叠以扩大内容区显示面积。
  • 右侧内容区。显示当前所选功能模块的完整界面。各模块内部可再分为列表区、编辑区与辅助面板区。

3.3　项目与工作区的概念

本软件以"项目"作为数据组织的顶层单元。一个项目对应磁盘上的一个工作目录，该目录内的文件、该项目下产生的研究会话、文献引用与知识条目，共同构成该项目的完整上下文。

项目具有以下特性：

  • 目标持久化。项目的研究使命、当前里程碑与历史关键决策作为长期状态保存，不随单次会话结束而失效。
  • 上下文隔离。不同项目的会话记录、记忆条目与知识库相互隔离，避免跨项目信息串扰。
  • 证据关联。项目内的文献、实验结果、代码与写作产物可相互引用，形成可追溯的证据链。

用户可在标题栏的项目选择器中切换当前项目，或新建项目并指定其工作目录。切换项目后，各功能模块的内容将同步更新为所选项目的数据。

第四章　研究对话工作区（Chat）

研究对话工作区是本软件的核心模块，用户在此发起研究请求、审批工具调用、查看研究产物并驱动审查修订循环。

4.1　新建与管理研究会话

研究对话工作区界面分为左侧会话列表、中部对话区与右侧工作面板三栏。

  1. 点击左侧会话列表顶部的"新建会话"按钮，创建一个新的研究会话。
  2. 新建会话默认归属于当前项目。若需要在其他项目下工作，请先在标题栏切换项目。
  3. 会话创建后自动以首轮内容生成标题；用户可右键点击会话条目重命名、置顶、归档或删除。
  4. 会话列表支持按项目分组显示，并可通过顶部搜索框按标题或内容检索历史会话。

4.2　发起研究请求

在对话区底部的输入框中键入研究请求后，按 Ctrl + Enter 或点击发送按钮提交。输入框支持以下几类输入：

  • 自然语言描述。直接描述研究目标、待解决的问题或需要执行的操作。
  • 文件引用。输入"@"符号后弹出文件选择菜单，可从当前项目工作目录中选择文件，被引用的文件内容将纳入本轮上下文。
  • 技能调用。输入"/"符号后弹出技能选择菜单，列出当前可用的科研流程技能。选定技能后，该技能的流程说明将作为本轮的执行指引。
  • 图像输入。可直接粘贴剪贴板中的图像，或拖拽图像文件至输入框；亦可使用全局截图快捷键抓取屏幕区域后送入。
  • 附件上传。点击输入框左侧的附件按钮，选择本地文件作为本轮附件。

    • 提交后，对话区将以流式方式逐步显示模型的推进过程，包括思考过程摘要、工具调用记录与最终产出内容。

    4.3　工具调用与权限审批

    在推进研究工作的过程中，软件会按需调用内置工具执行具体操作，例如读写文件、执行命令、检索文献、运行计算单元等。涉及修改用户数据或访问外部网络的工具调用需要用户审批。

    1. 当出现需要审批的工具调用时，对话区中会插入一张权限请求卡片，显示工具名称、目标对象与具体参数。
    2. 阅读请求内容后，选择"允许本次"以仅批准当前这一次调用，或选择"始终允许"以批准同类调用在本会话中不再询问。
    3. 选择"拒绝"将终止该次调用；软件会收到拒绝结果并据此调整后续步骤。
    4. 已批准的工具调用在执行完成后会折叠为一行摘要，点击摘要可展开查看完整的调用参数与返回结果。

    说明：权限审批的授权范围限于当前会话。切换会话或重启软件后，"始终允许"的授权需要重新给出。涉及删除数据、发送外部消息等不可逆操作的工具，始终逐次询问。

    4.4　独立审查闭环

    独立审查是本软件区别于通用对话软件的核心机制。执行角色模型完成一个阶段的研究工作后，审查角色模型以独立身份对方法、证据与论证提出质疑，审查意见回流至执行阶段触发修订，如此循环直至满足质量门限。

    1. 在对话区顶部的角色指示条中确认执行角色与审查角色所使用的模型。二者应来自不同的模型服务，以保证审查的独立性。
    2. 当一轮研究工作产出结论后，点击"发起独立审查"，或由技能流程自动触发。
    3. 审查面板将在右侧展开，逐条列出审查意见。每条意见标注其严重程度与所针对的具体证据位置。
    4. 查看审查结论标识：通过、有条件通过或未通过。未通过时，点击"应用审查意见"将意见回流至执行阶段，触发下一轮修订。
    5. 修订完成后可再次发起审查，直至审查结论为通过。每一轮审查记录均保留在会话中，可供回溯。

    4.5　上下文压缩与分层记忆

    4.5.1　上下文压缩

    当会话长度超出模型的上下文容量时，软件自动启动上下文压缩。压缩机制由三部分构成：

    • 固定上下文。研究目标、关键约束与用户明确要求保留的内容被标记为固定内容，逐字保留并随压缩滚动前移，不参与摘要。
    • 递归归并。历史轮次按块进行摘要，摘要结果再次归并，避免简单丢弃早期内容导致的信息断裂。
    • 覆盖度门禁。压缩完成后执行确定性的覆盖度校验，若关键信息未被覆盖则重新压缩。

    压缩过程在对话区中以一条分隔提示显示。压缩前的完整记录被归档保存，可通过会话检索功能查回。

    4.5.2　分层记忆

    软件在每一轮对话结束时，将本轮中产生的稳定事实以结构化条目写入项目记忆。后续会话在满足词项门禁与配额预算的条件下，召回相关记忆条目并注入上下文。记忆条目按项目隔离，可在"设置—记忆"分区中浏览、编辑与删除，详见第 13.4 节。

    4.6　侧栏工作台

    对话区右侧的工作面板以标签页形式承载两类内容：

    • 任务标签页。显示当前会话中派生出的子任务及其进度，点击可查看子任务的详细执行记录。
    • 文件标签页。显示本轮涉及的文件内容。文本文件以带语法高亮的只读视图呈现；PDF 文件以内置阅读器呈现，支持翻页与文本选取。

    点击对话区中的文件路径链接，即可在侧栏中打开对应文件而不离开当前对话。侧栏宽度可拖拽调整，也可整体收起。

    4.7　中断、续跑与重试

    1. 中断。在模型推进过程中点击"停止"按钮，可中断当前回合。被中断的回合及其已完成的部分产出会被完整保留，不会回滚。
    2. 续跑。中断后可继续输入新的指示，软件在保留已有进展的基础上继续推进，无需从头重来。
    3. 重试。若某一回合因网络或模型服务异常而失败，该回合会标记为失败状态并显示"重试"按钮。重试以非破坏性方式恢复该回合，已完成的工具调用结果不会重复执行。
    4. 回合回滚。在会话历史中选定某一回合，可将项目文件状态回滚至该回合执行前的快照，用于撤销一次不理想的自动修改。

    第五章　实验计算模块（Lab）

    实验计算模块提供交互式计算笔记本环境，用于执行数据处理、模型训练、结果分析等计算任务。模块支持两类计算内核，并可由研究对话工作区以结构化方式驱动，实现"描述实验意图—自动修改并执行笔记本—回收结果"的闭环。

    5.1　计算内核的选择与启动

    1. 点击左侧导航栏的"实验"进入本模块。
    2. 在界面顶部的内核选择器中选择计算内核类型。软件支持基于 Python 的 Jupyter 内核与 MATLAB 内核两类。
    3. 首次使用某类内核时，软件会自动检测本机是否已安装对应运行环境。未安装时给出提示与安装指引。
    4. 选定内核后点击"启动"。内核启动成功后，状态指示灯转为就绪状态，并显示内核版本信息。
    5. 内核在会话期间保持常驻，变量状态在多次执行之间保留。点击"重启内核"可清空全部变量并重新开始。

    说明：MATLAB 内核采用文件通信方式实现常驻会话，以规避批处理模式下每个单元格需重新启动解释器所带来的额外开销。

    5.2　笔记本的编辑与执行

    笔记本由若干单元格顺序组成，每个单元格为代码单元格或文本单元格。

    操作方法
    新建单元格点击单元格之间的插入按钮，或在选中单元格时使用插入命令
    切换单元格类型在单元格工具条中选择"代码"或"文本"
    执行单个单元格点击单元格左侧的运行按钮，或按 Ctrl + Enter
    执行并跳至下一格按 Shift + Enter
    顺序执行全部单元格点击工具栏"全部运行"
    中断执行点击工具栏"中断"，向内核发送中断信号
    移动与删除单元格拖拽单元格调整顺序；在单元格工具条中执行删除
    保存笔记本按 Ctrl + S；标签页上的圆点标识表示存在未保存修改

    代码单元格提供语法高亮、括号匹配与自动缩进。输入过程中按 Tab 触发内核级自动补全，补全候选来自内核当前的真实命名空间；将光标置于函数名上按 Shift + Tab，可查看该函数的签名与文档说明。

    5.3　变量检视器

    界面右侧的变量检视器实时显示当前内核命名空间中的变量。检视器为语言感知设计，针对不同内核显示相应的类型信息。

    • 列表显示变量名、类型与尺寸信息。数组与矩阵类变量额外显示维度。
    • 点击变量名展开查看其取值预览。大型数组仅显示前若干元素以避免界面卡顿。
    • 检视器在每次单元格执行完成后自动刷新，也可手动点击刷新按钮。

    注意：MATLAB 语言的标识符不允许以下划线开头，在 MATLAB 内核下创建此类变量名将导致执行错误。

    5.4　集成终端

    模块底部提供集成终端面板，用于执行与实验相关的命令行操作，例如安装依赖包、查看数据文件、启动辅助进程等。

    1. 点击底部"终端"标签展开终端面板。
    2. 终端的工作目录默认为当前项目的工作目录。
    3. 终端为完整的伪终端实现，支持交互式命令、彩色输出与光标控制序列。
    4. 可创建多个终端标签页并行使用；点击标签页上的关闭按钮结束对应终端进程。

    5.5　长输出与图像结果的处理

    为避免超长输出拖慢界面，模块对执行输出做以下处理：

    • 长文本裁剪。超出阈值的文本输出仅显示开头与结尾部分，中间以省略标识替代，并提供"显示完整输出"按钮按需展开。
    • 输出清空指令。支持内核发出的清空输出指令，用于进度条等需要原地刷新的场景，避免逐帧堆积。
    • 图像输出。绘图结果以图像形式内嵌在单元格下方显示，可右键另存为文件，或直接引用至学术排版模块作为论文插图。
    • 错误输出。执行错误以突出样式显示完整回溯信息，便于定位问题所在的代码行。

    第六章　学术排版模块（Typeset）

    学术排版模块提供面向学术论文的排版工程编辑与编译环境，内置排版引擎，无需用户另行安装排版软件。

    6.1　打开与新建排版工程

    1. 点击左侧导航栏的"排版"进入本模块。
    2. 模块自动扫描当前项目工作目录中的排版工程并在左侧文件树中列出。
    3. 点击"新建工程"可基于内置模板创建论文工程，模板包含主文档、参考文献库与插图目录的标准结构。
    4. 在文件树中点击文件即可在编辑区打开。文件树支持新建、重命名、删除与拖拽移动。

    说明：模块会自动推断排版工程的编译根文档。当用户打开的是被主文档引入的子文件（例如独立的插图源文件）时，编译根仍锁定在主文档，不会随当前打开的文件而收窄。

    6.2　源码编辑模式

    源码模式下编辑器直接呈现排版语言源码，并提供以下辅助能力：

    • 语法高亮与括号匹配。区分命令、环境、数学模式与注释。
    • 命令自动补全。输入反斜杠后弹出命令候选；输入引用与参考文献命令时，候选列表来自当前工程中已定义的标签与文献条目。
    • 符号面板。提供分类的数学符号与希腊字母面板，点击即可插入对应命令。
    • 表格与插图向导。通过对话框设置行列数、对齐方式、图片路径与标题，自动生成规范的表格或插图代码块。
    • 文档结构大纲。侧栏显示章节层级结构，点击可快速跳转。

    6.3　可视化编辑模式

    可视化模式在同一份源文档上以所见即所得的方式呈现内容，用户直接编辑渲染后的文本，软件同步维护底层源码。该模式支持标题层级、加粗与斜体等文字样式、行内与行间数学公式、引用与交叉引用、列表与标题区块的直接编辑。

    点击编辑区工具栏的模式切换按钮可在源码模式与可视化模式之间切换。两种模式作用于同一份文档，切换不会产生中间副本。

    6.4　编译与预览

    1. 点击工具栏的"编译"按钮，或使用保存快捷键触发自动编译。
    2. 编译过程中状态指示条显示当前进度；编译完成后右侧预览面板自动刷新为最新结果。
    3. 编译产生的警告与错误在底部日志面板中分类列出。点击错误条目可跳转至源码中的对应行。
    4. 编译成功后，软件自动为当前文档状态打上里程碑标记，便于后续回滚至可编译的版本。
    5. 预览面板工具栏提供翻页、缩放、适应宽度与全文搜索功能。当工具栏宽度不足时，次要按钮自动收入溢出菜单而非被隐藏。

    6.5　正反向定位

    • 正向定位。在源码中按下定位快捷键，预览面板自动滚动至该行对应的排版位置并高亮显示。
    • 反向定位。在预览面板中双击任意位置，编辑区自动跳转至生成该位置内容的源码行。

    说明：反向定位依据排版引擎生成的位置映射数据实现。对于中日韩文字，排版引擎按单字记录位置，因此定位精度可达到字符级。

    6.6　外部变更审核

    当排版工程中的文件被本软件之外的程序修改时（例如用户使用其他编辑器编辑，或由自动流程写入），软件会检测到变更并进入审核流程，避免未经确认的改动直接覆盖当前编辑内容。

    1. 检测到外部变更时，编辑区顶部出现审核横幅，显示受影响的文件数量。
    2. 点击"查看变更"展开审核面板，逐文件显示差异对照。差异以行级高亮标出新增、删除与修改内容。
    3. 对每个文件选择"接受"或"拒绝"。接受则采用外部版本，拒绝则保留当前编辑器中的版本。
    4. 对同时存在本地修改与外部修改的文件，软件执行三方合并并在存在冲突处给出标记，由用户在审核面板中直接编辑消解。
    5. 全部文件决策完成后点击"应用"，审核结果写入工程。

    注意：审核范围仅覆盖工程源文件，编译产生的中间文件与输出文件不纳入审核，因此拒绝外部变更不会影响用户已有的编译产物。

    第七章　文献管理模块（Literature）

    文献管理模块负责研究文献的检索、组织、阅读与引用，并为研究对话工作区提供文献证据的检索来源。

    7.1　文献检索

    1. 点击左侧导航栏的"文献"进入本模块，切换至"检索"标签页。
    2. 在检索框中输入检索式。检索式支持关键词、作者、标题与年份范围等条件组合。
    3. 在来源选择器中勾选参与本次检索的文献数据来源。软件支持多个学术数据来源并行检索。
    4. 点击"检索"。各来源并行发起请求，结果汇总后按相关性排序展示。
    5. 检索结果自动执行跨来源去重合并。同一篇文献在多个来源中命中时，保留元数据最完整的记录并标注其全部来源。
    6. 勾选需要的条目后点击"加入文献库"，将其纳入当前项目的文献库。

    说明：单一来源请求失败不会导致整次检索失败，软件会标注该来源不可用并返回其余来源的结果。使用中文检索词时，软件会同时给出译词检索以覆盖英文文献。

    7.2　文献库的组织

    "文献库"标签页以列表形式展示当前项目已收录的全部文献。

    • 筛选与排序。支持按年份、作者、期刊来源、阅读状态与标签筛选，按相关性、年份或加入时间排序。
    • 标签管理。为文献添加自定义标签以建立主题分组，一篇文献可属于多个标签。
    • 查重。点击"重复项检测"，软件扫描全库并列出疑似重复的文献对，由用户确认后合并。
    • 批量操作。支持批量添加标签、批量导出与批量删除。

    7.3　全文阅读与标注

    1. 在文献列表中选中一篇文献，点击"阅读"打开内置阅读器。
    2. 若该文献尚无本地全文，可点击"下载全文"由软件获取，或点击"关联本地文件"手工指定已有的全文文件。
    3. 阅读器支持翻页、缩放、文本选取与全文搜索。
    4. 选中文本后可添加高亮标注并附加批注文字。标注保存在项目数据中，再次打开时恢复。
    5. 点击"送入对话"可将当前选中的段落连同文献出处一并发送至研究对话工作区作为讨论素材。

    软件在文献入库时抽取其全文文本并建立混合检索索引，使研究对话工作区能够在全文层面检索证据，而不仅限于标题与摘要。

    7.4　引用关系图谱

    "图谱"标签页以节点图形式展示文献之间的引用关系。节点代表文献，连线代表引用方向。

    • 节点大小反映该文献在当前文献库中的被引次数。
    • 点击节点高亮其全部引用与被引关系，并在侧栏显示该文献的详细信息。
    • 支持按年份区间过滤节点，用于观察某一主题的演进脉络。
    • 支持缩放与拖拽平移，并可将当前视图导出为图片用于论文插图。

    7.5　参考文献导入导出

    操作说明
    导入书目文件支持导入常见的书目交换格式文件，批量建立文献条目
    导入全文文件直接导入本地全文文件，软件从文件中抽取元数据建立条目
    导出书目将选中文献导出为多种书目格式，供排版工程或其他文献软件使用
    写入工程书目直接将选中文献写入当前排版工程的参考文献库文件
    添加标识符通过文献标识符直接检索并添加单篇文献

    7.6　综述工作流

    综述工作流将文献综述的撰写过程拆分为若干顺序阶段，每个阶段有明确的产出与通过条件，前一阶段未通过时不进入下一阶段。

    1. 在"工作流"标签页点击"新建综述工作流"，填写综述主题与范围。
    2. 工作流按阶段依次推进：确定检索策略、构建候选文献池、按质量与配额筛选、逐篇精读提炼、分主题归纳、撰写各节、整体校验。
    3. 每个阶段完成后产出阶段性文档，并由独立审查角色进行阶段校验。
    4. 阶段校验未通过时，工作流停留在当前阶段并给出修订要求；通过后方可推进至下一阶段。
    5. 工作流状态持久保存，可随时中断并在之后继续，不要求一次性完成。

    说明：候选文献池按目标配额的若干倍规模构建，再依质量指标筛选填充各类别配额，以保证综述的文献覆盖面与代表性。

    第八章　知识库模块（Knowledge）

    知识库模块以结构化知识点的形式，沉淀研究过程中形成的判断、结论与领域事实，使其可被后续研究会话检索与复用。知识库采用分权归属设计：模型负责生成候选知识点草稿，研究者负责逐条确认，只有经研究者确认的条目才成为正式知识。

    8.1　知识点的生成与确认

    1. 点击左侧导航栏的"知识"进入本模块，界面分为待确认区与已确认区两部分。
    2. 研究对话过程中，软件识别出具有长期价值的事实性内容时，自动生成知识点草稿并置于待确认区。用户也可在对话中选中任意文本，点击"提炼为知识点"手动发起。
    3. 待确认区中的每条草稿显示知识点陈述、来源会话链接与自动归类的主题。
    4. 逐条审阅草稿：点击"确认"将其收入已确认区；点击"修改"可先编辑表述再确认；点击"丢弃"删除该草稿。
    5. 确认后的知识点进入已确认区，参与后续会话的知识召回。

    说明：模型只能向待确认区写入草稿，不具备直接写入已确认区的权限。这一设计确保知识库中的正式内容均经过研究者的人工核验，避免未经验证的自动推断沉淀为长期事实。

    8.2　知识库检索

    已确认区提供检索能力，用于在大量知识点中定位所需内容。

    • 全文检索。在检索框中输入关键词，软件对知识点陈述执行检索并按相关度排序返回。检索支持中文分词，无需完整词组匹配。
    • 主题筛选。侧栏按主题聚合展示知识点数量，点击主题名筛选该主题下的全部条目。
    • 来源追溯。每条知识点保留其来源会话与来源轮次的链接，点击可跳转至产生该知识点的原始对话上下文。
    • 编辑与删除。选中条目后可修改其陈述与主题归类，或将其删除。修改历史随条目保存。

    8.3　知识库与研究会话的联动

    知识库并非独立的资料仓库，而是研究会话上下文的组成部分。联动方式如下：

    联动方向行为
    会话 → 知识库对话中产生的稳定结论自动生成草稿，等待研究者确认
    知识库 → 会话新会话启动时，软件按当前研究主题召回相关知识点并注入上下文，避免重复交代已有结论
    知识库 → 文献知识点可关联至支撑其成立的文献条目，点击可直接跳转至该文献
    知识库 → 写作在学术排版模块中可检索知识库内容作为写作素材，并携带其来源出处

    知识库按项目隔离。切换项目后，模块展示的是所选项目自身的知识条目，不同项目之间的知识不会相互串扰。

    第九章　代码工作区（Code）

    代码工作区为研究项目中的程序代码提供浏览与编辑环境，使代码实现与研究过程处于同一工作台内，无需切换至外部开发工具。

    9.1　打开代码工作区

    1. 点击左侧导航栏的"代码"进入本模块。
    2. 模块以当前项目的工作目录作为根目录载入工程。切换项目后工作区随之切换。
    3. 首次打开时需要初始化编辑环境，界面显示加载进度，初始化完成后进入工作区。

    9.2　文件浏览与编辑

    • 文件树。左侧以树形结构展示工程目录。支持展开折叠、新建文件与文件夹、重命名、删除与拖拽移动。
    • 多标签编辑。打开的文件以标签页形式排列，可并行编辑多个文件。标签页上的圆点标识表示存在未保存的修改，按 Ctrl + S 保存。
    • 语法支持。编辑器对常见编程语言提供语法高亮、括号匹配、代码折叠与自动缩进。
    • 查找替换。支持当前文件内查找替换，以及跨工程的全局检索。
    • 界面语言。编辑环境提供中文界面，与软件整体语言设置保持一致。

    9.3　版本库状态查看

    当项目工作目录处于版本控制之下时，代码工作区显示版本库状态信息。

    • 文件树中以颜色标识区分新增、已修改与未跟踪的文件。
    • 侧栏的版本控制面板汇总列出当前工作区的全部变更文件。
    • 点击变更文件可查看其与上一版本的行级差异对照。
    • 可在面板中查看当前分支名称与提交历史。

    说明：代码工作区中由研究对话自动执行的代码修改，同样会在版本控制面板中体现为工作区变更，便于研究者集中复核自动修改的范围。

    第十章　邮件模块（Mail）

    第十一章　扩展与技能管理（Extensions）

    11.1　技能体系概述

    技能是本软件中对科研流程的声明式封装。每个技能以文档形式定义其适用场景、执行步骤与产出要求；当研究请求匹配某技能的适用场景时，该技能的流程说明即作为本轮执行的指引，使软件按既定方法论推进而非自由发挥。

    本软件内置七十余个技能，覆盖科研工作的主要环节：

    环节技能示例
    文献调研文献检索与综述、单篇论文精读、查新核验、引用核对

    实验执行实验方案规划、实验代码实现、批量实验队列、结果分析、消融实验规划
    独立审查研究评审、对抗式评审、实验诚信审计、论文数据核对、证明校验
    论文写作大纲规划、分节撰写、插图生成、排版编译、海报与幻灯片制作
    投稿重投审稿意见答复、换会场重投、格式适配

    1. 点击左侧导航栏的"扩展"进入本模块，切换至"技能"标签页。
    2. 列表按环节分组展示全部技能，每项显示技能名称、触发说明与启用状态。
    3. 通过每项右侧的开关启用或停用该技能。停用的技能不参与自动匹配，也不出现在对话输入框的技能选择菜单中。
    4. 点击技能名称展开查看其完整流程说明。
    5. 点击"安装技能"可从本地目录导入第三方技能包。导入前软件会展示该技能的声明内容供用户核验。

    11.3　外部工具服务的接入

    1. 点击"添加服务"，填写服务名称与启动方式。启动方式可以是本地可执行程序，也可以是远程服务地址。
    2. 保存后软件尝试连接该服务并拉取其工具清单，连接状态显示于服务条目上。
    3. 展开服务条目可查看其提供的全部工具及各工具的参数说明。
    4. 可按工具粒度控制启用状态，仅开放研究工作确需的工具。
    5. 外部服务提供的工具在被调用时同样受权限审批机制约束，其调用请求会在对话区中显示为权限请求卡片。

    注意：外部工具服务以独立进程或远程连接方式运行，其行为不受本软件直接控制。请仅接入来源可信的服务，并在启用前核验其工具清单。

    第十二章　任务管理（Tasks 与 Scheduled）

    12.1　待办任务看板

    待办任务看板用于管理需要软件自主执行的研究任务。与研究对话的交互式推进不同，看板中的任务在独立环境中自动执行，用户在执行完成后集中复核结果。

    1. 点击左侧导航栏的"任务"进入看板。看板按状态分列展示：待处理、执行中、待复核、已完成。
    2. 点击"新建任务"，填写任务描述。任务描述应当自包含，即不依赖某次对话的上下文也能被理解与执行。
    3. 任务创建后进入待处理列。点击"开始"将其推入执行队列。
    4. 执行中的任务显示实时进度与当前步骤。点击任务卡片可展开查看完整的执行记录。
    5. 执行完成后任务进入待复核列，展示其产生的全部文件改动。
    6. 在复核面板中逐项查看改动差异，选择"合并"采纳改动，或选择"丢弃"放弃本次执行结果。

    12.2　隔离工作区与任务合并

    任务在隔离工作区中执行。隔离工作区是项目工作目录的独立副本，任务执行期间的全部文件改动只发生在该副本中，不影响用户正在编辑的主工作区。

    机制说明
    工作区隔离每个任务分配独立副本，多个任务并行执行互不干扰；用户在主工作区的编辑不会被任务改动打断
    自动执行授权因执行范围被限制在隔离副本内，任务执行期间的常规文件操作无需逐次审批，避免长时间任务因等待确认而停滞
    两阶段合并复核通过后，先将主工作区的最新状态并入隔离副本，消解冲突后再将结果合并回主工作区，避免覆盖用户在任务执行期间所做的修改
    执行代际任务重新执行时生成新的执行代际编号，先前代际的产出保留可查，不被覆盖
    内部数据排除软件自身的运行状态目录不纳入任务改动范围，避免配置与会话记录被任务误改

    注意：任务在隔离环境中自动执行，无法向用户提问。因此任务描述中应当写明全部必要的前提与判断依据，避免任务因信息不足而停滞。

    12.3　定时任务编排

    1. 点击左侧导航栏的"定时"进入定时任务模块。
    2. 点击"新建定时任务"，填写任务名称与任务内容。
    3. 设置执行周期。支持按固定间隔执行，或按指定的时刻表周期执行。
    4. 指定该任务所归属的项目。任务执行时以该项目的工作目录与上下文为准。
    5. 设置有效期。到期后任务自动停止，避免长期遗留的任务持续占用资源。
    6. 保存后任务进入调度列表，显示下次执行时间与最近一次执行结果。
    7. 在列表中可随时暂停、恢复、手动触发或删除定时任务。

    定时任务的典型用途包括：定期检查某研究主题的最新文献、周期性运行回归实验并汇报结果差异、定时整理知识库中的待确认条目。

    • 召回预览。输入一段测试文本，可预览在该输入下软件将召回哪些记忆条目，用于验证召回策略是否符合预期。

    • 写入策略。设置记忆写入的触发条件，或整体关闭记忆写入功能。
    • 清空记忆。按项目清空全部记忆条目。该操作不可撤销，执行前会二次确认。

    1. 进入"远程"分区，开启远程控制开关。
    2. 填写自托管网关地址。网关由用户自行部署，软件不提供公共中转服务。

    5. 配对成功的设备出现在已授权设备列表中，可随时解除授权。
    6. 远程连接采用端到端加密，通信内容对网关不可见；单次配对的授权范围限定于指定的会话标识。

    注意：远程控制功能默认关闭。开启前请确认自托管网关的部署环境安全，并在不使用时及时关闭该功能或解除设备授权。

    第十四章　常见问题与故障处理

    14.1　安装与启动类问题

    现象处理方法
    安装程序报告缺少界面渲染运行时且自动部署失败检查网络连接后重试；或从操作系统厂商官方站点手动下载该运行时并安装，然后重新运行安装程序
    双击快捷方式后无窗口出现在"关于"分区所示的日志目录中查看启动日志；若日志显示配置文件解析失败，可将配置文件重命名后重新启动，软件将重建默认配置
    主窗口关闭按钮无响应该现象通常由窗口权限配置异常引起。请更新至最新版本；如仍存在，可通过任务管理器结束进程后重新启动
    启动时短暂闪现命令行窗口属于外部组件启动时的显示行为，不影响功能。更新至最新版本后该现象已被抑制

    14.2　模型服务连接类问题

    现象处理方法
    模型清单为空进入"设置—模型"分区点击刷新；若仍为空，检查账户登录状态与网络连通性，并使用"测试连接"验证服务地址
    发起对话后长时间无响应且无报错点击"停止"中断当前回合后重新发送。软件对请求设有超时保护，超时后会自动重试；若持续出现，请在"模型"分区更换模型服务
    对话中途报告连接中断该回合会被标记为失败并保留已完成的部分。点击"重试"以非破坏性方式恢复，已完成的工具调用不会重复执行
    长会话响应变慢属于上下文接近容量上限时的正常现象。软件会自动执行上下文压缩；也可手动新建会话，已确认的知识点会自动召回

    14.3　计算内核类问题

    现象处理方法
    内核启动失败进入"设置—系统"分区查看环境检测结果，确认对应的计算运行环境已正确安装且可执行文件路径有效
    单元格执行后无输出检查内核状态指示灯是否为就绪。若显示忙碌但长时间无进展，点击"中断"；无效时点击"重启内核"
    变量检视器不显示变量点击检视器的刷新按钮；若内核刚经历重启，此前的变量已被清空，需重新执行相关单元格
    MATLAB 内核报告标识符非法MATLAB 语言的变量名不允许以下划线开头，请修改变量命名
    输出内容显示不完整超长输出默认折叠显示，点击"显示完整输出"展开

    14.4　排版编译类问题

    现象处理方法
    编译失败且日志提示缺少宏包内置排版引擎在首次使用某宏包时需联网获取，请确认网络连接后重新编译；获取后的宏包会缓存于本地，后续编译无需联网
    编译根文档识别错误在文件树中右键点击主文档，选择"设为编译根"以显式指定
    中文内容编译后显示异常确认文档使用了支持中文的排版类与字体设置，并确认源文件以 UTF-8 编码保存
    反向定位跳转位置偏差请先执行一次完整编译以更新位置映射数据，再进行定位
    预览工具栏按钮显示不全窗口宽度不足时次要按钮会收入溢出菜单，点击工具栏末端的更多按钮即可访问

    14.5　数据与备份

    本软件的数据分布于以下两处，备份时应同时覆盖：

    数据位置内容
    用户配置目录软件配置、账户凭据、会话记录、记忆条目、文献库与知识库数据库、运行日志。可在"设置—关于"分区中点击"打开数据目录"定位
    项目工作目录各研究项目自身的文件，包括代码、笔记本、排版工程与数据文件。位置由用户在创建项目时指定
    1. 备份。在软件完全退出的状态下，将上述两处目录复制到备份介质。运行中复制可能导致数据库文件处于不一致状态。

    附录E　数据目录结构说明

    本软件的数据分为用户配置数据与项目工作数据两部分。了解其目录结构有助于执行备份、迁移与故障排查。

    E.1　用户配置目录

    用户配置目录位于当前用户的应用数据路径下，可在"设置—关于"分区中点击"打开数据目录"直接定位。其主要内容如下：

    内容说明
    主配置文件界面语言、主题、启动行为等通用设置
    凭据文件模型服务与邮箱账户的授权凭据，加密存储
    项目注册表已创建项目的名称与工作目录路径对照
    会话记录目录按会话存放的完整对话记录与事件日志
    压缩归档目录上下文压缩前的完整历史记录，供检索回溯
    记忆数据库按项目隔离的长期记忆条目
    知识数据库按项目隔离的知识点条目与其来源关联
    文献库目录文献元数据库、全文文件与全文检索索引
    运行日志目录软件运行日志与模型请求日志，用于故障诊断
    用量日志本机使用统计的原始记录
    缓存目录排版引擎宏包缓存与界面资源缓存，可安全删除

    提示：缓存目录可在软件关闭后安全删除以释放磁盘空间，删除后软件会在下次使用时重新生成。其余目录请勿手动修改。

    E.2　项目工作目录

    项目工作目录由用户在创建项目时指定，存放该研究项目自身的全部文件。软件在该目录下维护一个内部状态子目录，用于保存项目级的运行状态与编辑历史。

    内容说明
    用户文件代码、计算笔记本、排版工程、数据文件等由研究者组织的内容
    内部状态子目录项目级运行状态、任务记录与编辑历史的影子版本库

    注意：内部状态子目录不纳入任务执行所产生的改动范围，也不应被手动编辑。将项目迁移至新路径时，该子目录应随项目工作目录一并复制，以保留编辑历史。

    E.3　备份范围速查

    备份场景需覆盖的范围
    完整备份用户配置目录 + 全部项目工作目录
    仅保留研究成果项目工作目录（不含内部状态子目录）
    更换计算机用户配置目录 + 全部项目工作目录；恢复后需核对项目注册表中的路径
    重装软件保留数据无需额外操作，卸载不会删除上述两处数据

    附录F　典型研究工作流程示例

    本附录以一个完整的研究周期为例，串联说明各功能模块在实际研究工作中的配合方式。示例假设研究者已完成软件安装与模型服务配置。

    F.1　阶段一：建立项目与确定方向

    1. 在标题栏的项目选择器中点击"新建项目"，填写项目名称并指定工作目录。
    2. 进入研究对话工作区，新建会话，用自然语言描述研究方向与约束条件。
    3. 在输入框中输入斜杠符号，从技能菜单中选择"想法生成"技能，由软件在该方向下生成并排序候选研究想法。
    4. 对选定的候选想法调用"新颖性核验"技能，对照近期文献确认该想法尚未被充分研究。
    5. 调用"方案细化"技能，将方向细化为问题锚定、可实现的方法方案。
    6. 确认方案后，软件将研究使命与当前里程碑写入项目状态，后续会话自动继承该上下文。

    F.2　阶段二：文献调研

    1. 进入文献管理模块，在检索标签页中输入检索式并勾选参与检索的数据来源。
    2. 检索结果经跨来源去重后，勾选相关条目加入项目文献库。
    3. 在文献库标签页中为文献添加主题标签，建立分组。
    4. 对关键文献点击"阅读"打开内置阅读器，选中重要段落添加标注，或点击"送入对话"交由软件提炼要点。
    5. 在图谱标签页中查看文献之间的引用关系，识别该主题的奠基性工作与近期演进。
    6. 软件在文献入库时已建立全文索引，后续研究对话可直接在全文层面检索证据。

    F.3　阶段三：实验设计与执行

    1. 返回研究对话工作区，调用"实验规划"技能，将研究方案转化为论断驱动的实验路线图，明确每项实验所支撑的论断。
    2. 调用"实验落地"技能，由软件在实验计算模块中创建计算笔记本并实现实验代码。此过程中涉及文件写入与命令执行的工具调用会提请审批。
    3. 进入实验计算模块，选择并启动计算内核，逐单元格执行并通过变量检视器确认中间结果符合预期。
    4. 对需要批量执行的参数组合，使用参数扫描功能一次性排队执行。
    5. 执行过程中可在集成终端中安装缺失的依赖包或查看数据文件。
    6. 实验完成后调用"结果分析"技能，生成对比表格与结论要点。

    F.4　阶段四：结果审查

    1. 调用"结果到论断"技能，判定当前实验结果支持哪些论断、哪些论断证据不足。
    2. 对证据不足的论断，依技能建议补充实验或收窄论断表述。
    3. 调用"实验诚信审计"技能，检查实验设计中是否存在基准设置不当、指标口径不一致等问题。
    4. 发起独立审查，由审查角色模型对方法与证据提出质疑。审查结论为未通过时，点击"应用审查意见"触发修订。
    5. 重复修订与审查，直至审查结论为通过。全部审查记录保留在会话中可供回溯。
    6. 将过程中形成的稳定结论在知识库模块中逐条确认入库，供后续研究复用。

    F.5　阶段五：论文撰写与投稿

    1. 调用"论文规划"技能，依据审查结论与实验结果生成论文大纲。
    2. 进入学术排版模块，基于内置模板新建论文工程。
    3. 调用"论文撰写"技能按节生成正文，或在编辑器中自行撰写。可视化编辑模式适合连续行文，源码模式适合调整公式与版式。
    4. 调用"论文插图"技能，由实验结果生成可发表质量的图表并插入工程。
    5. 在文献管理模块中选中引用文献，点击"写入工程书目"直接生成参考文献库。
    6. 按 Ctrl + S 触发编译，在预览面板中核对排版结果；编译错误可点击日志条目跳转至对应源码行。
    7. 调用"论文论断核对"与"引用核对"技能，零上下文核验论文中的每个数字与每条参考文献。
    8. 投稿后收到评审意见时，可经邮件模块将意见"送入对话"，调用"审稿答复"技能生成答复草稿。

    说明：上述五个阶段并非必须线性完成。研究过程中随时可以回到前序阶段补充文献、追加实验或修订方案；项目状态与知识库会持续累积，不因阶段回退而丢失。
