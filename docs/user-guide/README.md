# SomniQ Studio 用户手册

> 适用版本：**v0.4.86**（2026-10-22）· 平台：Windows 10/11 x64、macOS 12+

SomniQ Studio 是一个本地优先的自主科研桌面工作台。它把对话、文献、实验代码、LaTeX 写作、科研绘图和研究流程放在同一个项目里，由 **执行模型（Executor）** 推进工作、**独立审查模型（Reviewer）** 质疑结果，再回到执行端修订，直到达到质量标准。

本手册面向使用者，不涉及开发细节。第一次使用建议按顺序阅读前三章。
