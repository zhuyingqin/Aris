# LaTeX 写作

> 适用版本：SomniQ Studio v0.4.86 · [返回目录](README.md)

**LaTeX** 页面提供类似 Overleaf 的本地写作环境：文件树、源码 / 可视化编辑、编译、PDF 预览、源码与 PDF 双向跳转，以及对 AI 修改的逐处审阅和项目版本历史。

## 1. 准备 TeX Live

LaTeX 页面调用本机安装的 **TeX Live** 编译，应用本身不内置 TeX 发行版。

- 需要 `latexmk`、`xelatex`、`pdflatex`、`lualatex` 中至少一个位于系统 PATH（推荐完整安装 TeX Live，自带 `latexmk`）。
- 源码与 PDF 之间的跳转需要 `synctex`，它随 TeX Live 一起安装。
- 未检测到 TeX 时，LaTeX 文档库会显示“尚未安装系统 LaTeX”。点击 **前往对话安装**，助手会根据你的系统给出安装方案，在大体积下载或需要管理员权限前征求你的确认，安装完成后编译一个最小文档验证。

你也可以自行安装：

- Windows / Linux：从 TeX Live 官网 <https://tug.org/texlive/> 下载安装程序。
- macOS：安装 MacTeX <https://tug.org/mactex/>（基于 TeX Live）。

安装后重启 SomniQ Studio，可在 **设置 → 关于与环境 → 本地环境检查** 中确认 LaTeX 显示为“可用”。

## 2. 文档库与新建文档

打开 LaTeX 页面会先进入 **LaTeX 文档库**，列出当前项目中所有主 `.tex` 文档。

- **筛选**：全部 / 最近修改 / 收藏 / 论文与文章 / 演示文稿 / 学术海报 / 研究报告 / 编译完成 / 需要编译 / 已归档。
- **行操作**：打开文档、在文件夹中显示、添加收藏、归档文档。

**新建文档**：点击 **新建 LaTeX 文档**，选择起始模板：

| 模板 | 说明 |
| --- | --- |
| 论文与文章 | 常规论文 |
| 演示文稿 | 16:9 Beamer 幻灯片（metropolis 主题） |
| 研究报告 | 报告类文档 |
| 学术海报 | A1 Beamer 学术海报（beamerposter） |

新文档创建在项目的 `.somniq/papers|slides|reports|poster/<标题>/main.tex` 下。已有的论文项目可以直接用项目切换器打开其所在文件夹，文档库会自动识别其中的主文档。

> **中文文档**：模板默认是英文的，不含中文宏包。写中文请自行加入 `\usepackage{ctex}`（或使用 `ctexart` 等文档类），编译时会自动切换到 XeLaTeX。

## 3. 编辑

**左侧面板**：项目文件、审阅与修订、AI 助手（即嵌入的对话）、PDF。

**文件树**：新建文件、新建文件夹、从磁盘导入…、**设为主文档**（显示“主”标记）、重命名、创建副本、删除。**大纲** 视图按标题列出文档结构并统计字数。

**编辑模式**：**代码**（源码）与 **可视化** 两种，可随时切换。Beamer 文档还可以直接在编译出的幻灯片画布上 **直接编辑**、**添加文字**，再 **保存并更新预览**。

**工具栏**：加粗、斜体、插入数学公式（行内 / 行间）、插入链接、插入交叉引用、插入引用、插入图片（可设宽度、浮动位置、题注、标签）、插入表格、列表、插入符号、查找、拼写检查。

**编辑器设置**：字体、字号、行距、按键方案（默认 / Vim / Emacs）、自动补全、语法检查。

**项目全文搜索**：在 `.tex`、`.bib`、`.cls`、`.sty` 文件中搜索；**全部替换** 前会为每个被修改的文件保存源码快照。

**源码批注**：在光标或选区处添加批注，可以 **解决** 或 **重新打开**。

| 快捷键 | 作用 |
| --- | --- |
| Ctrl + S | 保存 |
| Ctrl + Enter | 编译 |

## 4. 插入文献引用

1. 点击工具栏的 **插入引用**，打开 **SomniQ 文献库** 选择器。
2. 按标题、作者、DOI 或 Citation key 搜索本项目文献库中的条目。
3. 点击 **插入 \cite{}**。

SomniQ 会把用到的条目写入单独的 `somniq-references.bib`，并自动补上 `\addbibresource` / `\printbibliography`（biblatex）或在 `\bibliography{}` 中追加。**你自己的 `.bib` 文件不会被改动**；如果同名文件已存在且不是 SomniQ 管理的，应用会提示并保持原样。

## 5. 编译与预览

点击 **重新编译**（或 Ctrl + Enter），编译中按钮变为 **停止编译**。

**编译选项**：

- **LaTeX 引擎**：根据源码自动判断 / pdflatex / xelatex / lualatex。自动判断时：
  - 优先读取文件开头的 `% !TeX program = xxx` 注释；
  - 使用了 `ctex`、`xeCJK`、`fontspec`、`unicode-math`、`ctexart` / `ctexbeamer` 文档类或 `\setCJKmainfont` 时用 **XeLaTeX**；
  - 使用了 `luatexja` 时用 **LuaLaTeX**；
  - 其他情况用 pdflatex。
- **保存时自动编译**
- **最长编译时间（分钟）**：默认 10 分钟，按项目保存。
- **遇到首个错误即停止** / **尝试在有错误时继续编译**
- **清除缓存并重新编译**：遇到奇怪的编译问题时先试这一项。

**编译日志**：可按全部 / 错误 / 警告 / 信息筛选，**打开源码位置** 跳到出错行，**复制原始日志**。对未定义的引用、`&` 误用、编译超时等常见问题会给出中文提示。

**PDF 预览**：页码、缩放、适应宽度 / 高度、**全屏放映**、**反色显示 PDF**（夜间阅读）。导出：**另存 PDF…**、**下载项目源码（.zip）**、其他输出文件。

**源码 ↔ PDF 跳转**：

- 源码 → PDF：**在 PDF 中查看**（跳到光标对应的 PDF 位置）。
- PDF → 源码：双击 PDF 中的位置，或 **在源码中查看**。
- 修改源码后、重新编译前，跳转位置是近似的；PDF 缺少 SyncTeX 数据时请先在 LaTeX 页面重新编译。

## 6. 审阅 AI 和外部修改

对话中的 AI、Git 操作或其他程序修改了 LaTeX 项目中的文件时，文件会带上 **待审** 标记，顶部出现 **变更集** 菜单：

- 逐处审阅：**查看修改**、**接受此处** / **拒绝此处**、**上一处 / 下一处修改**。
- 按文件：**接受本文件全部** / **拒绝本文件全部**。
- 按变更集：**接受整个变更集** / **拒绝整个变更集**。
- 审阅完成后点击 **应用已审阅修改**，你的决定才会写入文件。
- 有多批修改时，可以用 **修改批次** 切换。
- 修改过大无法逐处对比时，选择 **使用磁盘版本** 或 **保留我的草稿**。

> 有待审阅的修改时，保存和编译会被暂停，请先处理完审阅。

## 7. 版本历史与恢复

打开 **版本历史** → **项目版本历史**，它记录整个项目的文件（包括图片等二进制文件）和批注：

- **创建命名快照**：在投稿、大改前手动打一个快照。
- **比较两个版本**
- **恢复此文件**：立即恢复，不再确认，请先确认选中的版本
- **恢复项目**：恢复整个项目，会先弹出确认

有待审阅的变更集时不能恢复版本。

## 8. 当前限制

- **审阅与修订** 面板目前是演示界面：其中的批注是示例数据，“发起独立同行评审”**不会调用任何模型**，显示的“评估完成”和问题清单是固定的示例文字，**请勿将其当作真实审查结果**；“追踪修订”开关也没有实际效果。需要对论文做独立审查，请在对话中开启独立审查（见 [对话 · 独立审查](chat.md#9-独立审查)）或运行 `/research-review`、`/auto-paper-improvement-loop` 等技能。
- 暂不支持与 Overleaf 实时同步。
