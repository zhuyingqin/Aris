# 研究流程、待办与定时任务

> 适用版本：SomniQ Studio v0.4.86 · [返回目录](README.md)

这三个功能都在 **更多功能（···）** 菜单中（左侧图标栏，或页面顶部的功能切换器），用于让研究在你不盯着屏幕时也能持续推进：

| 功能 | 适合做什么 |
| --- | --- |
| **研究流程** | 按固定的多阶段协议，从研究主题一路推进到可投稿的综述论文 |
| **待办任务** | 把一件事交给 AI 在独立的 Git 工作树中无人值守地完成，审查后再合并 |
| **定时任务** | 按时间周期或新邮件自动触发一个任务 |

## 1. 研究流程

> 研究流程默认隐藏，请先在 **设置 → 常规 → 工作区** 中打开 **研究流程** 开关。外部文献检索需要 **Go 及以上会员**。

当前内置一个流程模板：**从研究主题到可投稿综述论文**。

### 新建

1. 在 **工作流首页** 点击 **新建综述工作流**。
2. 在 **定义研究入口** 中填写：
   - **研究主题或问题**
   - **关键词**（逗号或换行分隔）
   - **起始年份** / **结束年份**
   - **语言变体**：中文 / English
   - **学术数据源**：Scopus、OpenAlex、Semantic Scholar、Crossref、arXiv
3. 点击 **创建并进入计划阶段**。

首页按项目保存所有流程，每个流程可以 **打开**、**重命名**、**删除**。

### 16 个阶段

1. 研究范围与检索计划
2. 近五年综述全量检索
3. 真实综述资格核验
4. 覆盖核验与数量分支
5. 趋势与综述空白
6. 方向选择与研究问题
7. 矩阵式 Scopus 策略
8. 试检与误检优化循环
9. 高质量原始文献库
10. A/B/C/D 批量分级
11. 数据驱动的综述大纲
12. 论文到章节映射
13. 全文证据与综合
14. 证据约束的全文写作
15. 独立审稿与修订循环
16. 投稿包

> 当前版本中第 1–12 阶段可以执行，第 13–16 阶段只展示计划，暂不可运行。

除“方向选择”外，每个阶段都设有 **独立审查关卡**：审查通过才能进入下一阶段，未通过会列出问题，要求修订后重新审查。

### 需要你参与的节点

- **确认检索式**：第 1 阶段的计划通过审查后，点击 **确认检索式并开始侦察**；修改计划后点击 **保存当前计划并重新审查**。
- **确认外部检索**：每次执行外部检索前，先 **生成检索执行预览**，检查后再 **确认并执行**。
- **选择方向**：第 6 阶段会给出 3–5 个候选研究方向，点击 **选择此方向**。
- **确认矩阵策略**：点击 **确认并进入试检**，试检优化最多 4 轮。

### 自动侦察与预算

- 确认检索式后，流程会自动运行内部检查点，顶部横幅显示 **自动运行中 / 已暂停 / 等待选择方向 / 等待确认检索式**。遇到数据源或认证失败时会自动暂停，处理后点击 **恢复自动运行**。
- 根据找到的综述数量自动分支：少于 10 篇时回到检索审查；10–49 篇直接进入空白分析；50 篇及以上先聚类。
- **外部检索总预算**：50–10000 条，默认 500，按 4 条检索路径分配。
- 矩阵式策略阶段只使用 Scopus。

### 模型与审查

- **Executor 模型**：默认“使用当前设置”，也可以单独指定。
- **独立审查** 开关：关闭后，受影响的阶段会被标记为“未经独立审查”。审查模型来自 **设置 → 模型服务**。

### 回到之前的阶段

已完成的阶段可以只读查看。需要修改时使用 **回到这一步修改**、**重新选择方向**、**重新打开并提出修改意见**、**重新构建原始文献库** 等按钮。**注意：回到某一阶段会清除它之后的所有阶段。**

点击 **在悬浮窗中查看运行过程** 可以打开对话悬浮窗，向助手询问当前阶段的风险和下一步。

## 2. 待办任务

### 前提

项目文件夹必须是一个 **Git 仓库**（没有的话可以在对话输入框下方的 Git 按钮中 **初始化 Git 仓库**）。每个任务都在独立的 Git 工作树和分支中运行，不会弄乱你当前的工作目录。

### 新建任务

1. 打开 **更多功能 → 待办任务**，点击 **新建任务**。
2. 填写 **标题** 和 **任务说明**。任务会无人值守地运行，请把目标、约束和验收标准写清楚。
3. 选择 **仅保存到待办** 或 **创建并开始**。模型默认继承对话中的模型。

### 看板

任务按 **待办 / 进行中 / 待确认 / 已完成** 四列显示，可勾选 **显示已取消**。常见状态：排队中、准备工作树、执行中、等待你回答、独立审查中、按审查意见修改中、Agent 合并中、已中断、失败、已取消。

运行规则：

- 每个项目最多同时运行 2 个任务。
- 任务的文件修改落在它自己的工作树和分支中，在你 **接受并合并** 之前不会进入你的工作目录。
- 注意：在默认的 **自动批准** 权限下，任务执行的 shell 命令并不局限于工作树，可以访问电脑上的其他位置。请在任务说明中写清楚允许操作的范围，涉及重要数据的项目请谨慎使用。
- **独立审查** 跟随对话中的 **自动审核** 全局开关（默认关闭）。开关关闭时，任务完成后直接进入待确认，结论显示为“没有经过独立审查”；开启后，任务完成会经过独立审查，最多自动修订 2 轮，结论为：独立审查通过 / 独立审查要求修改 / 需要你来判断。

### 处理任务

- **回答问题**：任务卡片显示“任务需要你决定”时，选择选项或输入回复，点击 **回答**。
- **卡片操作**：查看会话、开始 / 重试、继续、暂停、停止、编辑、删除（会同时删除工作树）。
- **查看差异**：在审查面板中查看文件差异；**独立交付物**（不进仓库的产物）可以 **导出…**。
- **接受并合并**：确认结果后合并回项目。合并前项目需要仍处于创建任务时的分支；应用会先把基础分支合入任务工作树再快进合并，你自己的工作目录不会出现冲突。如有冲突，会交给合并 Agent 处理，完成后显示“已合并为 <提交号>”。
- **退回待办**：不满意时退回重新安排。

在任务的对话中，输入框会被任务状态栏替代，可点击 **返回待办任务** 回到看板。

## 3. 定时任务

打开 **更多功能 → 定时任务**（页面标题“已安排任务”），有 **任务列表** 和 **预设模板** 两个标签，可按 全部 / 运行中 / 已暂停 筛选。

### 新建

1. 点击 **创建计划任务**，填写名称和触发时要执行的提示词。
2. 选择 **所属项目** 和 **绑定对话**（需要该项目至少有一个已保存的对话）。
3. 选择 **触发类型**：
   - **按时间周期间隔**：每隔 N 分钟 / 小时 / 天（1–10000），或使用快捷间隔 15 分钟、30 分钟、1 小时、6 小时、1 天；
   - **收到新邮件时**：选择 **触发邮箱**（默认任意已连接邮箱账户），可填写 **匹配关键词**（匹配主题、摘要和发件人名称，不区分大小写）。
4. **执行模型** 默认跟随当前模型。点击 **创建任务**。

任务可以 **启动** / **暂停**、**查看对话记录**、**删除任务**（不可撤销）。

**预设模板**：“新邮件触发·论文求助回复”和“定时轮询·论文求助回复”，点击 **使用此模板** 快速创建。

### 运行规则

- 每次触发都会生成一张 **待办任务** 卡片，同样在独立工作树中运行，按 **自动审核** 开关决定是否经过独立审查，最后由你确认合并。因此项目需要是 Git 仓库，且绑定对话所属的项目仍在项目列表中。
- 上一次运行尚未结束时，本次触发会被跳过。
- 定时任务只在 **应用打开时** 运行；应用关闭期间错过的触发，会在下次启动时补跑一次。
- 新邮件触发目前只支持 **IMAP** 账户，Gmail / Outlook 授权登录的账户不会触发。
