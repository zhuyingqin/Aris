# 代码与实验

> 适用版本：SomniQ Studio v0.4.86 · [返回目录](README.md)

**代码** 页内置了一个完整的 VS Code 风格编辑器（基于 VSCodium），用来浏览和编辑项目代码、运行 Jupyter 笔记本、使用终端，并能把选中的代码一键交给对话中的助手。

## 1. 首次使用

1. 先在项目切换器中打开一个项目文件夹，否则会提示“请先选择一个项目文件夹。”。
2. 首次进入会弹出 **关于权限** 提示：内置终端和第三方扩展以你的系统账户身份运行，**不受对话权限模式的限制**。确认后点击 **继续**（只提示一次）。
3. 如果出现“首次使用需要准备编辑器运行时”，点击 **准备并启动**。应用会依次下载并解压运行时、安装 Python / Jupyter / MATLAB 扩展、启动编辑器，过程中可以 **取消**。
   - Windows 安装包已内置编辑器运行时，无需联网下载；macOS 首次使用时需要联网下载。
   - 默认扩展（Python、Jupyter、MATLAB 语言支持）从 Open VSX 安装一次。安装失败不影响编辑器打开；你卸载后的扩展也不会被自动装回。
4. 启动失败时显示“编辑器启动失败”，点击 **重试**。

> 编辑器界面语言跟随应用语言。第一次打开某个文件夹时，编辑器可能以“受限模式”打开，笔记本在你选择 **信任** 该文件夹之前不能运行。

## 2. 编辑器的使用

编辑器的用法与 VS Code 基本一致：文件资源管理器、搜索、Git、扩展市场（Open VSX）、内置终端等都可以直接使用。

底部状态栏有三个 SomniQ 专属入口：

| 入口 | 作用 |
| --- | --- |
| **SomniQ Code ▾** | 切换到其他 SomniQ 功能页 |
| 项目名 | 切换 SomniQ 项目；有未保存的修改时会询问是否 **保存并切换** |
| 账户 | 显示会员档位和剩余额度 |

### 把代码交给助手

1. 在编辑器中选中一段代码。
2. 右键选择 **Ask Aris about this selection**，或按 **Ctrl + Alt + A**（macOS：⌘ + ⌥ + A）。
3. 应用切换到 **对话**，输入框中预填“关于 <文件> 第 <行> 行：”和选中的代码。补充你的问题后发送。选区过长时会被截断并注明。

反过来，在对话中点击代码文件路径，会在代码页打开该文件。

## 3. Jupyter 笔记本与 Python

- 需要本机已安装 Python 和 Jupyter。可以在 **设置 → 关于与环境 → 本地环境检查** 中查看状态，缺失时点击 **前往对话安装**，助手会在下载或修改系统前征求你的确认。
- 打开 `.ipynb` 文件即可用 Jupyter 扩展运行单元格。

> 编辑器里运行的笔记本内核，与助手在对话中通过工具执行笔记本时使用的内核是 **分开的**，两者之间的变量不互通。

## 4. MATLAB

- 编辑器中提供 MATLAB 语言支持（语法高亮等），不提供 MATLAB 笔记本内核。
- 本机装有 MATLAB 时，助手可以在对话中通过笔记本工具驱动 MATLAB 会话执行代码。应用会自动检测本机的 MATLAB，会话启动约需 10–20 秒。

## 5. 算力面板

点击 **显示算力面板** 打开右侧的算力面板，可以把当前文件作为持久化计算任务运行在本机或其他已配对的电脑上：

1. 在 **计算目标** 中选择 **本机 Worker** 或已配对的电脑（显示在线 / 离线）。
2. 设置 **超时（秒）**（默认 1800）和需要 **回传产物** 的文件匹配规则。
3. 打开一个 `.ipynb` 或 `.py` 文件，点击 **在所选节点运行当前文件**。
4. 在 **计算任务** 列表中查看状态（排队 / 准备 / 运行中 / 成功 / 失败 / 已取消 / 超时 / 已中断）、日志和产物，必要时 **取消任务**。

远程电脑需要先在 **设置 → 远程控制** 中配对，并在对方电脑的 **本机能力** 中允许接受远程代码任务（见 [手机远程](plugins-mail-remote.md#3-远程控制与手机)）。
