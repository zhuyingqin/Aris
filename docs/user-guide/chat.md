# 对话

> 适用版本：SomniQ Studio v0.4.86 · [返回目录](README.md)

**对话** 是 SomniQ Studio 的主工作区。你在这里描述研究任务，执行模型会检索文献、读写文件、运行代码和命令、编译论文；开启独立审查后，审查模型还会核查结果并要求修订。

> 说明：部分卡片和提示在中文界面下仍显示英文（如权限卡片的 Continue / Skip、问题卡片的 Submit、工具状态 Running / Succeeded / Failed）。本手册按界面实际显示的文字描述。

## 1. 项目与对话列表

### 项目

对话归属于项目。项目的添加、切换在页面顶部的 **项目切换器** 中完成（见 [快速上手](quick-start.md#4-添加第一个项目)）。

- 切换项目时，如果科研绘图草稿还在保存，或 LaTeX 有未保存的修改，应用会先阻止或询问。
- 在对话侧栏中右键项目名：**新建任务**、**在资源管理器中显示**、**从列表中移除项目**（默认项目不能移除；移除只是不再显示，不会删除文件夹）。
- 项目可以在侧栏中拖动排序；有新对话活动的项目会自动排到前面。

### 对话侧栏

点击对话页顶部的 **显示或隐藏对话侧栏** 按钮打开侧栏，Esc 关闭。

- **新建对话**：侧栏顶部的 **新建任务**，或项目名旁的 **+**（在此项目中新建任务）。
- **分组**：**置顶** 在最上方，其下是 **本机项目**，每个项目一个文件夹。每组默认显示 5 条，点击 **更多对话 (n)** 展开。
- **状态点**：运行中 / 未读。
- **对话菜单**：点击 **···** 或右键。菜单打开后也可以按字母键：
  - **置顶 / 取消置顶**（P）
  - **标为未读 / 标为已读**（U）
  - **重命名**（R），也可以双击标题直接改，Enter 保存、Esc 取消
  - **删除**（D）：删除后 6 秒内可点 **撤销** 恢复，之后永久删除
- **标题**：新对话会根据内容自动生成标题，并在前几轮后刷新一次；手动重命名后不再自动修改。
- **运行位置**：侧栏顶部可以选择在 **本机** 还是已配对的远程电脑上运行（见 [手机远程](plugins-mail-remote.md)）。远程运行的对话不支持附件。

> 属于 **待办任务** 或 **研究流程** 的对话不能在这里删除，请到对应页面管理。

## 2. 输入框

| 操作 | 方式 |
| --- | --- |
| 发送 | Enter |
| 换行 | Shift + Enter |
| 回复进行中输入 | 可以继续输入下一条草稿，回复结束后再发送 |
| 停止回复 | 回复进行中，发送按钮变为 **停止回复** |

### 引用文件：`@`

1. 输入 `@` 和文件名的几个字母。
2. 弹出 **文件** 选择器：**最近**（最多 6 个最近使用的文件）和 **搜索结果**（最多 40 个项目内匹配文件）。
3. 选中后文件以附件形式加入本条消息。

### 命令与技能：`/`

输入 `/` 打开斜杠菜单（↑↓ 选择 · Enter 使用 · Esc 关闭），分为系统命令、最近使用的技能和全部技能三组，支持模糊匹配。常用命令见 [第 10 节](#10-斜杠命令速查)，技能见 [第 11 节](#11-内置科研技能)。

### 附件

- **添加方式**：点击输入框的 **+**（附加文件）；把文件拖到对话区任意位置（出现“拖放文件以附加”）；或直接粘贴剪贴板里的文件、图片。
- **限制**：单次最多 20 个文件；图片超过 8 MB 时以说明文字代替；粘贴的文本超过 1 MB 会被截断；其他文件最大 512 MB。
- 附件以卡片形式显示在输入框上方，图片带缩略图，点 × 移除。
- 也可以用全局截图快捷键把屏幕区域直接发到对话，见 [第 12 节](#12-全局截图)。

### 权限模式

输入框下方的权限按钮决定 AI 调用工具时是否需要你确认：

| 模式 | 行为 |
| --- | --- |
| **计划** | 只读：可以阅读和分析，但拒绝修改文件或执行命令 |
| **接受编辑** | 可以直接修改项目文件；执行 shell 命令等需要完全访问的操作时会询问 |
| **询问** | 每个需要授权的工具调用都先询问你 |
| **自动批准** | 不再询问，直接执行（**默认**） |

- 回复进行中不能切换权限模式。
- 权限模式只约束 SomniQ 自己的工具，**不会** 授予操作系统管理员权限。
- 也可以输入 `/permissions` 切换。

> **建议**：处理重要数据或不熟悉的项目时，先切换到 **询问** 或 **接受编辑**，确认 AI 的操作方式后再放开。

## 3. 回复过程中看到什么

- **思考过程**：回复时显示“正在思考 · N 秒”，结束后折叠为“已处理 N 秒”，点击可展开。
- **工具卡片**：每次工具调用一张卡片，显示状态（Running / Succeeded / Failed）和工具名，点击展开查看输入与输出。修改过的文件会显示路径，点击可打开。连续多次调用同一工具会合并显示计数。常见的中文卡片有：
  - **网页检索 · 关键词**（已完成 · N 条 / 部分结果）
  - **本地文献证据 · 查询**（已定位 N 条 / 未找到证据），见 [文献](literature.md#5-在对话中引用文献库)
  - **Somni 绘图**
- **长时间运行的命令**：显示已用时间 / 超时时间、进程号，以及实时输出的末尾几行。
- **等待提示**：模型 3 秒没有响应时显示“等待模型响应 · 已 m:ss”；超过 60 秒会提示模型可能在深度推理。连接不稳定时会自动重试，并显示“模型连接暂时不稳定，正在重试”。
- **步骤条**：AI 制定了多步计划时，输入框上方会显示“第 X / N 步 · N 个文件”，展开可查看流程和本次涉及的文件。
- **提问目录**：一个对话里有 2 个以上的提问时，右侧会出现 **本轮对话提问目录**，点击跳转；右下角的 **回到底部** 返回最新消息。

## 4. 模型与思考强度

点击输入框下方的模型按钮，打开 **模型与思考强度** 面板：

- **选择模型**：按系列分组列出账号下的模型，旁边显示价格倍率（见 [账号、会员与模型](account-and-models.md#5-执行模型与审查模型)）。
- **思考强度**：不思考 / 最少 / 低 / 中 / 高 / 很高 / 最高。点击 **恢复默认强度（高）** 恢复默认。
- 回复进行中不能调整思考强度；切换模型会在下一轮生效。
- 也可以输入 `/model` 切换执行模型、`/reviewer` 切换审查模型，不带参数时会弹出列表供选择。

输入框右侧、模型按钮旁的 **上下文圆环** 显示当前对话已用的上下文比例：绿色（50% 以下）、琥珀色（80% 以下）、红色（更高）。接近自动压缩阈值时会出现提示；达到阈值后应用会自动压缩较早的上下文，界面上的历史消息仍然保留。也可以手动输入 `/compact` 压缩，后面可以附加压缩时的要求。

## 5. 权限确认与提问卡片

### 权限确认

在 **询问** 或 **接受编辑** 模式下，AI 要执行需要授权的操作时，回复中会出现权限卡片，显示工具名和所需权限：

- **Continue**：允许本次操作
- **Skip**：跳过本次操作
- **Show input**：查看 AI 准备执行的具体内容

回复会一直等待你的选择，没有超时。点击停止回复视同 Skip。

### 提问卡片

AI 需要你做决定时，会在回复中显示一张问题卡片：

- 单选题：点击选项即提交。
- 多选题：勾选后点击 **Submit**。
- 大多数问题都可以在文本框中输入自己的回答，Enter 提交。

回复停止或结束后，未回答的问题卡片会失效。

## 6. 停止、继续、重试与编辑

| 场景 | 操作 |
| --- | --- |
| 中途停止 | 点击 **停止回复**。消息下方显示“回复已停止”和 **继续** 按钮，点击从中断处接着做 |
| 回复出错 | 显示“回复失败”和错误信息，点击 **重试**。已完成的工作会保留，从出错处继续 |
| 对成功的回复不满意 | 点击 **重试**，回到该提问重新生成回复 |
| 修改之前的提问 | 在自己的消息上点击 **编辑并重新发送**。发送后会替换该消息之后的全部对话 |
| 复制内容 | 消息上的 **复制** 按钮 |

> “编辑并重新发送”只改写对话，不会自动撤销 AI 已经修改的文件。需要撤销文件改动请用下一节的方法。

## 7. 审核与撤销文件改动

AI 在某一轮修改了文件后，回复末尾会出现 **已编辑 N 个文件 +新增行 −删除行** 的卡片：

- **审核**：逐个文件查看修改前后的差异。
- **撤销**：撤销这一轮的全部文件改动。如果文件在之后又被修改过，应用会报告冲突或部分撤销的情况。

LaTeX 文件的修改另有更细致的逐处审阅流程，见 [LaTeX 写作](latex.md#6-审阅-ai-和外部修改)。

## 8. 项目摘要

点击对话页顶部的 **显示项目摘要**，打开项目摘要卡片（有任务运行时按钮上会显示“N 个任务正在运行”）：

- **自动审核** 开关：开启后，实质性任务完成时由独立 Reviewer 核验。这是全局开关，对所有项目以及待办任务、定时任务都生效。
- **子智能体**：当前项目中正在协作的子智能体。
- **版本状态**：Git 分支、工作区是否干净、变更数量。
- **后台运行中**：后台进程列表，可查看 **日志** 或 **停止**。
- **项目使命**、**长期目标**、**当前里程碑**、**成功标准**（已验证的会打勾）、**最近进展**，以及当前工作与主线的关系（当前核心工作 / 相关工作 / 偏离主线）。

项目目标从你的第一个实质性请求中自动提炼；识别完成前卡片显示“SomniQ 正在从持续对话中识别本项目的长期目标。”。可以用 `/goal` 管理目标：

```text
/goal status              查看当前目标
/goal replace <新目标>     替换目标
/goal pause / resume      暂停（会停止所有正在运行的工作）/ 恢复
/goal complete            标记目标完成
```

## 9. 独立审查

SomniQ Studio 的核心机制：执行模型完成工作后，由 **另一个模型** 以独立身份审查。

### 开启

1. 在 **设置 → 模型服务** 中选择与执行模型 **不同** 的 **Reviewer 模型**（或在对话中输入 `/reviewer`）。
2. 打开 **项目摘要** 中的 **自动审核** 开关。该开关 **默认关闭**，并且是全局设置：在任一项目中打开，所有项目的对话、待办任务和定时任务都会启用独立审查。

### 什么时候会触发审查

开启后，一轮回复结束时满足以下任一条件就会自动审查：

- 这一轮修改了文件、执行了命令、编译了 LaTeX、下载了文件或启动了子智能体；
- 你明确要求审查，例如“请审查”“帮我审查”“请验证”“继续修改”；
- 论文、实验、实现等研究类请求，并且使用了检索或执行类工具。

只是询问之前的审查结果（如“审查结果是什么”“提了什么问题”）时不会再次触发；侧边任务中不会触发。

### 独立性保证

- 审查模型必须与执行模型不同，否则显示“独立 Reviewer 当前不可用”。
- 审查模型只能 **读取** 项目文件，不能修改；不读取疑似密钥的文件；**看不到** 执行模型的对话过程，只看产物和证据。
- 每轮审查最多 14 步或 10 分钟；点击停止回复也会同时停止审查。

### 你会看到什么

回复中会出现审查徽标，状态依次可能是：“正在独立审核” → “Executor 正按意见修订 n/2” → “已通过审核” / “要求继续修订” / “需要用户决策”。

点击徽标，在右侧打开 **独立 Reviewer** 面板：

- 执行模型与审查模型的身份；
- 审查结论：通过 / 需要修订 / 需要用户决策 / 审查不可用；
- 每一轮审查的发现的问题、已核查证据、审查时调用的工具、缺失的检查和修订要求；
- **清除审查记录** 按钮（审查进行中不可用）。

### 规则

- 每次最多 **自动修订 2 轮**。2 轮后仍未通过时会提示，需要你决定下一步。
- 如果审查只提出了低严重度的问题，结论记为通过；只有低 / 中等严重度问题且没有缺失的检查项时，也记为通过。这些问题会作为改进建议保留。

## 10. 斜杠命令速查

| 用途 | 命令 |
| --- | --- |
| 信息 | `/help` 帮助、`/status` 状态、`/cost` 用量、`/version` 版本、`/diff` 查看改动 |
| 模型与权限 | `/model`、`/reviewer`、`/permissions [模式]`、`/setup`（打开设置） |
| 上下文 | `/compact [要求]` 压缩上下文；`/clear --confirm` 丢弃当前上下文、开始新的会话（不带 `--confirm` 只提示） |
| 计划 | `/plan <任务>` 只生成计划、不修改文件，确认后用 `/plan execute` 执行；`/tasks` 查看本对话中 AI 的步骤清单（不是“待办任务”看板） |
| 项目目标 | `/goal start / status / pause / resume / replace / complete` |
| 记忆 | `/memory pending`、`/memory approve <id>`、`/memory reject <id>`、`/memory approval on / off` |
| 代码与 Git | `/init`（为项目生成 AGENTS.md）、`/commit`、`/pr`、`/issue`、`/bughunter` |
| 会话 | `/session list / search <关键词> / switch / timeline`、`/export [文件名]` 导出对话、`/export-debug-zip` 导出调试包 |
| 技能 | `/skills list`、`/skills show <名称>`、`/<技能名>` 运行技能 |

> 侧栏没有按内容搜索对话的输入框；要按关键词查找历史对话，请使用 `/session search <关键词>`。

## 11. 内置科研技能

技能是预先编排好的科研工作流，输入 `/技能名` 并附上说明即可运行，例如 `/research-lit 扩散模型做蛋白质设计的最新工作`。完整列表可以输入 `/skills list` 查看。

| 类别 | 技能 |
| --- | --- |
| 文献调研 | `research-lit`、`literature-search`、`literature-screen`、`literature-evidence`、`arxiv`、`openalex`、`novelty-check`、`research-wiki`、`wiki-enrich` |
| 选题与规划 | `idea-creator`、`idea-discovery`、`research-refine`、`experiment-plan`、`formula-derivation`、`research-pipeline` |
| 实验 | `experiment-bridge`、`run-experiment`、`monitor-experiment`、`training-check`、`analyze-results`、`result-to-claim`、`ablation-planner`、`experiment-audit`、`dse-loop` |
| 论文写作 | `paper-plan`、`paper-write`、`paper-writing`、`paper-compile`、`paper-figure`、`figure-spec`、`mermaid-diagram`、`latex-diagrams`、`overleaf-sync` |
| 审查与修订 | `research-review`、`auto-review-loop`、`auto-paper-improvement-loop`、`kill-argument`、`citation-audit`、`paper-claim-audit`、`proof-checker`、`proof-writer`、`rebuttal`、`resubmit-pipeline` |
| 学术报告 | `paper-slides`、`paper-talk`、`slides-polish` |
| 专利与软著 | `patent-disclosure-skill`（中国专利）、`patent-draft`、`patent-novelty`、`patent-pipeline`、`soft-copyright` |
| 其他 | `grant-proposal`（基金申请）、`render-html`、`web-design` |

在 **设置 → 插件 → 技能** 中可以浏览技能说明，也可以安装受管技能（如 PPT Master）。

## 12. 全局截图

在任何应用中按 **Ctrl + Shift + A**（macOS：⌘ + Shift + A）：

1. 所有屏幕冻结，拖动框选区域，或单击某个窗口直接框住它。
2. 用工具栏标注：矩形、椭圆、箭头、画笔、荧光笔、马赛克、文字（可调颜色和粗细）。Ctrl + Z 撤销，Ctrl + Shift + Z 或 Ctrl + Y 重做。
3. 选择结束方式：
   - **发送到聊天**：图片加入对话输入框，并切换到对话页；
   - 双击或 Enter：复制到剪贴板；
   - Ctrl + T：**钉住** 在屏幕上；
   - Esc：逐步退出。

快捷键可以在 **设置 → 常规 → 工作区 → 截图快捷键** 中修改（必须包含修饰键，冲突时会提示）。

## 13. 右侧侧边面板

点击对话页顶部的侧栏按钮，或按 **Ctrl + Alt + B**（macOS：⌘ + ⌥ + B）打开右侧面板。点 **+**（新增侧栏标签）可以添加：

| 标签 | 用途 |
| --- | --- |
| **新建侧边任务** | 继承项目上下文的只读旁路对话，适合临时“定位代码”“解释报错”“核对事实”，不影响主对话，也不保存到项目 |
| **查看代码修改** | 查看当前项目的代码改动 |
| **打开图片工作流** | 在侧栏中处理图片 |
| **打开文件…** | 在侧栏阅读 PDF、Markdown、代码等文件 |

- 标签可关闭；拖动边缘调整宽度，双击边缘恢复默认宽度。
- **发送到主任务**：把侧栏中的结果或选中的文字加入主对话的输入框。
- 子智能体也会以 **子智能体** 标签出现在这里。
- 每个对话分别记住自己的侧栏标签。

**文件查看器** 提供 **预览 / 源码** 切换、**重新读取**、**在 Code 页面打开**、**用系统程序打开**、**在资源管理器中显示**。

**点击对话中的文件路径**：代码文件在 **代码** 页打开，`.tex` 在 **LaTeX** 页打开，PDF 和图片在侧栏打开，其他文件用系统程序打开。右键文件路径还可以 **附加为上下文**、**复制路径**、**复制相对路径**、**复制文件名**、**在侧栏阅读**。

## 14. 导出对话

对话页顶部提供：

- **导出当前对话**：导出为文件，便于存档或分享。
- **导出故障调试包**：遇到问题时导出调试信息，回复进行中也可以导出，反馈问题时请附上。

## 15. 记忆

SomniQ Studio 会在对话结束时提炼研究中的事实、结论和偏好，在之后的对话中按需召回。对话页顶部的记忆标识显示本轮载入了多少条记忆。

- **写入方式**：在 **设置 → 常规 → 工作区 → 记忆策略** 中选择 **自动写入** 或 **写入前确认**。选择后者时，用 `/memory pending` 查看待确认的记忆，`/memory approve <id>` / `/memory reject <id>` 批准或拒绝。
- **查看与修正**：在 **设置 → 智能记忆 → 科研记忆库** 中搜索、**修正** 或 **删除** 记忆条目，用 **召回预览** 查看某个问题会召回哪些记忆。删除派生记忆不会删除原始对话。
- 研究流程中的对话不会写入记忆。

更多记忆设置见 [设置 · 智能记忆](settings-and-data.md#智能记忆)。
