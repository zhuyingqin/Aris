# 科研绘图

> 适用版本：SomniQ Studio v0.4.86 · [返回目录](README.md)

**科研绘图** 用于生成可编辑的科研示意图：模型架构图、流程图、理论关系图、机制图、图形摘要等。生成结果是 **SVG 矢量图**，可以继续在画布中编辑，或通过对话修改，最终导出为 SVG / PNG / PDF 插入论文或幻灯片。

> 数据图表（柱状图、折线图等）请提供真实数据，并优先在对话中让助手用代码绘制，以保证数据准确。

## 1. 准备工作

- 打开一个项目（绘图结果保存在项目中）。
- 在 **设置 → 模型服务** 中确认：
  - 执行模型支持图像输入（科研绘图需要“视觉 Executor”，否则状态显示“需配置视觉 Executor”）；
  - 已选择与执行模型 **不同** 的 Reviewer 模型；
  - 如果需要 AI 先生成参考图，打开 **Somni 绘图 → 通过 Somni 账号绘图** 并选择绘图模型。

## 2. 新建绘图

1. 在左侧 **项目绘图** 栏点击 **新建绘图**。
2. **第 1 步：描述图形**
   - 用文字描述要画的图（最长 40,000 字），说清楚模块、连接关系和要强调的信息。
   - 不知道怎么写时，点击 **快速示例**（神经网络架构 / 训练流程 / 方法对比 / 系统工作流），或 **学科示例** 载入完整的场景示例（如 OFDM、HMM、Transformer、智能体、MAPK 信号通路等）。
   - 可选：**添加参考图**（或直接拖入图片），支持 PNG、JPEG、WebP，不超过 10 MB。有参考图时将直接以它为基础重建 SVG，不再调用生图模型。
3. **第 2 步：设置**
   - **图形风格**：六种视觉类型（技术框图、抽象关系图、模块分区、张量与空间、图标叙事、科学图解），以及布局（跟随内容 / 优先横向 / 优先纵向）、配色（克制 / 鲜明 / 黑白灰）、间距（均衡 / 紧凑 / 宽松）、**印刷适配**。也可以直接选预设：学术扁平、极简线框、柔和分区、印刷高对比。
   - **模型**：
     - **Executor · 重建 SVG**
     - **Reviewer · 独立审查**
     - **生图模型**（有参考图时显示“已有参考图，不调用”）
     - 点击 **模型设置** 可跳转到设置页。
4. 点击 **生成图形**（上传了参考图时为 **预览参考图**）。

> Executor 和 Reviewer 必须是不同的模型。如果你把 Executor 选成了当前 Reviewer 的模型，Reviewer 会自动换成另一个；仍然冲突时会提示“执行模型与审查模型相同，请更换其中一个模型以进行独立审查。”，**生成图形** 按钮在修正前不可用。

## 3. 生成过程

顶部步骤条：描述 → 生成 → 编辑 → 导出。

后台的详细流程是：理解需求 → 生成参考图（或导入参考图）→ 视觉检查 → 重建 SVG → 独立审查 →（必要时修订一次）→ 定稿。

可能的结果状态：

| 状态 | 含义 |
| --- | --- |
| 结构与视觉通过 | 审查通过，可以直接使用 |
| 结构通过 · 视觉待检查 | 结构没问题，建议你目视检查 |
| 草稿 · 待检查 | 尚未通过审查 |
| 输出达到上限 | 模型输出被截断，见下文 |
| 请求结果不明 | 网络或服务异常，结果无法确认 |
| 已取消 | 你取消了任务 |

运行中可以 **取消任务**。

**输出达到上限时**：卡片会显示模型实际输出的令牌数与保存下来的 SVG 字符数，并提示是否有大量隐藏推理占用了额度。应用不会自动重试，你可以：

- **换个 Executor 新建 · 复用参考图**：换一个模型重建，不会重新生成参考图；
- **查看并手动修复原始输出**。

**运行记录** 列出每次模型请求的类型、模型、状态、是否截断、令牌用量和耗时，便于排查问题。

## 4. 编辑与修改

生成后有四种视图：

| 视图 | 用途 |
| --- | --- |
| **PNG 修改** | 在参考图上圈选区域，用文字描述修改，再重建 SVG |
| **画布** | 内置 SVG 编辑器，直接拖动、改字、改颜色 |
| **对照** | 并排对比参考图与导出效果 |
| **SVG 源码** | 直接编辑 SVG 代码 |

**PNG 修改**：

1. 用 **自由圈选** 或 **矩形** 选择区域，或选择 **整图修改**。
2. 填写 **修改要求**，点击 **修改选区**。
3. 选择采用方式：**仅应用圈选修改（推荐）** / **使用整张修改图** / **保留原图**。
4. 点击 **下一步** 重建 SVG。

**对话修改**：在 SVG 对话修改框中描述修改，例如“把右侧模块向下移，箭头改成虚线”，点击 **修改 SVG**。每次修改都保存为新版本并重新审查。有未保存的编辑、正在查看历史版本或上一个请求尚未完成时，不能发起对话修改。

**版本与草稿**：

- 编辑会自动保存为草稿；点击 **保存新版本** 固定下来，或 **放弃编辑**。
- **版本** 下拉框列出 v1…vN；从历史版本保存会生成新版本，不会覆盖。
- **审查**：手动触发一次独立审查。**产物与审查** 面板显示结构 / 视觉审查结果、问题清单和各版本。
- **用相同输入新建**：在 **任务输入** 中用同样的描述和设置重新开始。

**删除**：会删除参考图、草稿、全部版本和运行记录，不可恢复。运行中的任务需要先取消。

## 5. 导出

有未保存的编辑时，先点击 **保存新版本**，再点击 **导出**：

| 格式 | 适用场景 |
| --- | --- |
| SVG | 矢量，可继续编辑 |
| PNG | 位图，适合预览和幻灯片 |
| PDF | 矢量 PDF，适合插入论文 |

默认文件名为 `figure-<编号>.<扩展名>`。
