# 设置与本地数据

> 适用版本：SomniQ Studio v0.4.86 · [返回目录](README.md)

按 **Ctrl + ,**（macOS：⌘ + ,），或从账户菜单点击 **设置** 打开设置页。设置默认打开 **常规**。

## 设置页一览

| 分组 | 页面 | 内容 |
| --- | --- | --- |
| 个人 | **个人资料** | 头像、账户额度、会员购买、用量统计、调用明细、退出登录 |
| 个人 | **常规** | 外观与语言、聊天背景、工作区模块开关、截图快捷键、记忆策略 |
| 模型与集成 | **模型服务** | 执行模型、Reviewer 模型、审查方式、绘图模型、辅助模型、文献检索与网络代理 |
| 模型与集成 | **智能记忆** | 记忆运行模式、待确认记忆、科研记忆库、召回预览、导出记忆 |
| 模型与集成 | **插件** | MCP 服务器与技能 |
| 模型与集成 | **邮箱** | 连接 Gmail / Outlook / IMAP 邮箱（需先在常规中启用邮箱） |
| 模型与集成 | **远程控制** | 手机或其他电脑的配对与权限 |
| 系统 | **关于与环境** | 应用更新、本地环境检查、检索工具可用性 |

**个人资料** 与 **模型服务** 详见 [账号、会员与模型](account-and-models.md)；**插件**、**邮箱**、**远程控制** 详见 [插件、邮箱与手机远程](plugins-mail-remote.md)。

## 常规

所有修改立即生效，并显示“已保存”。

**外观与语言**

- **模式**：浅色 / 深色 / 跟随系统
- **主题色**：默认蓝 / 紫色 / 青色 / 绿色 / 橙色 / 粉色 / 自定义
- **背景风格**、**界面字体**
- **界面语言**：简体中文 / English，同时决定助手回复使用的语言，也决定应用从哪里下载更新（中文走国内镜像，英文走 GitHub）
- **界面字号**：自动适应，或自定义 12–20 px

**聊天背景**

- 背景图片：无 / 远山 / 星轨 / 方格 / 本地图片
- **导入图片**：PNG / JPEG / WebP，不超过 12 MB，只保存在本机
- 图片透明度、显示方式（铺满 / 完整显示 / 平铺）

**工作区**

- **邮箱**、**研究流程** 开关：控制这两个模块是否出现在导航中（默认关闭）
- **截图快捷键**：默认 Ctrl + Shift + A，可修改或恢复默认
- **记忆策略**：自动写入 / 写入前确认

**高级**（默认折叠）

- 高级外观：正文字号、减少动画、编辑器字体 / 字号 / 行距
- 外观方案：**导出主题** / **导入主题** / **恢复默认**（不包含本地背景图片）
- 查看当前的系统提示词与用户提示词（只读）

## 智能记忆

**记忆运行模式** 是全局设置，对所有项目生效；**科研记忆库** 和 **召回预览** 展示的是 **当前项目** 的记忆。

- **记忆运行模式**：
  - **正常启用**：正常写入和召回记忆；
  - **灰度验证** / **观察**：用于验证记忆效果的过渡模式；
  - **仅 R0**：只保留原始对话，不使用派生记忆（相当于关闭记忆功能）。
- **待用户确认的 R3**：需要你确认的长期记忆，点击 **确认并允许注入** 后才会在对话中使用。
- **科研记忆库**：浏览记忆的各个层级（权威对话 / 研究原子 / 研究情景 / 研究画像），搜索事实、结论或对话，对条目 **修正** 或 **删除**。删除派生记忆不会删除原始对话。
- **召回预览**：输入一个问题，点击 **预览注入**，查看助手会召回哪些记忆。
- **补录历史记忆**：**扫描历史**、**加入 v2 队列**、**重新筛查被拒回合**，用于从旧对话中补充记忆。这些操作可能消耗模型额度，执行前会确认。
- **导出记忆**：导出到本地文件。

## 关于与环境

**应用更新**：显示当前版本；**检查更新** → **下载并安装**（显示进度）→ **重启应用**。详见 [安装教程 · 更新](installation.md#7-更新)。

**本地环境检查**：检测 Python、Jupyter、MATLAB、LaTeX 以及 Node、uv、OCR 等工具，状态为 可用 / 需检查 / 未检测到。缺失时点击 **前往对话安装**，由助手协助安装。这里还可以设置 **首选 Python / Conda 环境**：点击 **选择目录**，再点 **使用此环境**。

**检索工具可用性**：检查各检索工具是否可用，可点击 **重新检测**。

## 本地数据存放位置

SomniQ Studio 是本地优先的应用：项目文件、对话、文献库都保存在你的电脑上，只有调用模型、检索外部数据库、同步账号时才会访问网络。

| 内容 | 位置 |
| --- | --- |
| 配置文件 | `~/.config/SomniQ/config.json`（Windows：`C:\Users\<用户名>\.config\SomniQ\config.json`） |
| 项目列表、所有项目的对话记录与运行状态 | `~/.config/SomniQ/desktop-runtime/` |
| 技能 | `~/.config/SomniQ/skills/` |
| 邮箱连接 | `~/.config/SomniQ/mail/` |
| 记忆 | `~/.config/SomniQ/memory/` |
| 项目的文献库、文件编辑历史、临时文件 | `<项目文件夹>/.somniq/` |
| 登录凭据 | 系统凭据管理器（Windows 凭据管理器 / macOS 钥匙串） |
| 界面偏好、头像等 | 应用内置浏览器存储（Windows：`%LOCALAPPDATA%\com.aris.studio\`） |

> 高级用户可以通过环境变量 `ARIS_CONFIG_ROOT` 把配置目录改到其他位置。

**备份建议**

- 定期备份 `~/.config/SomniQ/`（对话历史、记忆）和各项目的 `.somniq/`（文献库、编辑历史）。
- 文献库页面底部提供 **备份数据库**。
- 如果项目使用 Git，建议把 `.somniq/` 加入 `.gitignore`，避免把文献库数据库和临时文件提交到仓库。

**换电脑迁移**：在新电脑上安装应用并登录后，把旧电脑的 `~/.config/SomniQ/` 复制到新电脑同一位置，项目文件夹（含 `.somniq/`）复制过去后，在项目切换器中重新 **添加本地项目**。
