# 插件、邮箱与手机远程

> 适用版本：SomniQ Studio v0.4.86 · [返回目录](README.md)

这三项都在 **设置 → 模型与集成** 分组中配置。

## 1. 插件（MCP 与技能）

打开 **设置 → 插件**（页面标题“扩展与技能”），有 **MCP** 和 **技能** 两个标签。

### MCP 服务器

MCP（Model Context Protocol）服务器可以为助手提供额外的工具，例如浏览器自动化、调用其他 AI 编程工具等。

**已配置的 MCP** 列表显示每个服务器的状态：已验证 / 验证失败 / 运行时就绪 / 需要设置 / 未验证 / 本机可用 / 本机不可用。点击 **验证全部** 一次性检测所有服务器。

**添加预设服务器**：在 **可添加的 MCP** 中点击 **添加**。

| 预设 | 用途 | 前提 |
| --- | --- | --- |
| **Playwright** | 浏览器自动化（打开网页、获取 PDF 等） | 应用已内置运行时；Windows 使用系统自带的 Microsoft Edge，macOS 使用 Google Chrome（需已安装） |
| **Codex** | 外部推理与独立审稿 | 本机已安装并登录 Codex CLI，且在 PATH 中 |
| **Claude Code** | 使用 Claude Code 工具 | 本机已安装并登录 Claude Code CLI，且在 PATH 中 |

**添加自定义 MCP**：

1. 点击 **添加自定义 MCP**。
2. 填写 **名称**、**命令**、**参数**（每行一个）、**环境变量**（`KEY=value`，每行一个）、**超时秒数**。
3. 点击 **添加 MCP**（编辑已有服务器时按钮为 **保存设置**），再点击 **检测工具** 验证（需先保存再验证）。
4. 保存后，**下一条对话** 才会加载新工具。

使用须知：

- 目前只支持以命令行方式启动的 **STDIO** 服务器，HTTP / SSE 类型的服务器会被识别但不会运行。
- MCP 配置是全局的（保存在 `~/.config/SomniQ/mcp.json`），对所有项目生效。
- 来自 `~/.claude.json`、`~/.claude/settings.json` 等外部配置的服务器以只读方式显示，需要在源文件中修改。
- 项目中的 `.mcp.json` 只会在全局配置文件尚不存在时导入一次。
- MCP 工具需要完全访问权限：对话权限为 **自动批准** 时直接运行，**询问** / **接受编辑** 时会弹出权限确认，**计划** 模式下会被拒绝。
- 浏览器类工具空闲 120 秒或累计运行 600 秒后会超时。

**Oracle**：SomniQ 受管的扩展，提供网页咨询、图片生成和独立审稿。点击 **安装 Oracle**，再在 **账号与用途设置** 中完成浏览器登录和用途分配。

### 技能

**技能** 标签列出所有可用技能，可搜索；选中后可以查看说明、路径、参数、所用工具和完整的 `SKILL.md`。来源标记为“内置”或“本地”。

- **添加自己的技能**：把包含 `SKILL.md` 的文件夹放到 `~/.config/SomniQ/skills/`（所有项目可用）或 `<项目文件夹>/.somniq/skills/`（仅该项目可用）。
- **受管技能 PPT Master**：用于制作可编辑的 PPTX 并逐页预览。提供 **安装** / **更新** / **修复运行时** / **卸载**；需要本机已安装 Python 并联网。

在对话中输入 `/技能名` 即可运行技能，见 [对话 · 内置科研技能](chat.md#11-内置科研技能)。

## 2. 邮箱

> 邮箱默认隐藏，请先在 **设置 → 常规 → 工作区** 中打开 **邮箱** 开关，之后导航的 **更多功能** 中和设置页中才会出现邮箱。

### 连接邮箱

打开 **设置 → 邮箱**（页面标题“邮箱连接”）：

- **使用 Gmail 继续** / **使用 Outlook 继续**：通过浏览器授权登录。
- **通用 IMAP/SMTP**（适用于其他邮箱，或授权登录不可用时）：
  1. 填写 **邮箱地址** 和 **显示名称**，点击 **自动发现** 填入服务器配置，必要时手动修改 **收件 IMAP** 和 **发件 SMTP**。
  2. 如果只想让助手读取和整理邮件、不允许发信，关闭 **启用 SMTP 发件**。
  3. 点击 **测试连接**，成功后点击 **连接邮箱**。

常见邮箱的注意事项：Gmail 使用 IMAP 时需要“应用专用密码”；Outlook 只支持授权登录；网易邮箱需要使用“授权码”而不是登录密码。

已连接的账户显示在 **已连接账户** 中，可随时 **断开连接**。

### 邮箱页面

打开 **更多功能 → 邮箱**：

- 文件夹：收件箱 / 已发送 / 草稿 / 已归档 / 垃圾邮件 / 已删除 / 星标邮件 / 重要邮件。
- **写邮件**；搜索邮件、联系人或关键词。
- 阅读邮件时可以 **回复**、**回复全部**、**转发**、**稍后处理**（标为未读）、**标为已读 / 未读**、**归档**、**删除**、加星标。
- 当前版本中，邮件附件的查看和下载暂不可用。

### 让助手处理邮件

连接邮箱后，在对话中可以让助手搜索、阅读、整理（标记、归档、加星、移动、删除）和发送邮件，例如：

```text
找出最近一周导师发来的邮件，按需要我回复的优先级列出来。
```

发送邮件属于对外操作。建议把对话权限设为 **询问**，这样每次发信前都会先让你确认。

邮件还可以触发定时任务，见 [定时任务](workflows-and-tasks.md#3-定时任务)。

## 3. 远程控制与手机

打开 **设置 → 远程控制**（页面标题“远程连接”），可以用手机或另一台电脑远程查看和继续桌面上的对话。连接优先使用点对点直连，无法直连时自动回退到加密中继，不需要额外配置服务器。

### 配对手机

1. 点击 **添加设备** → **添加**（会自动开启远程控制）。
2. 屏幕上出现配对二维码，**5 分钟内有效**。用手机相机扫码，会在浏览器中打开 SomniQ 的远程页面。
   - 手机无法扫码时，点击 **复制连接码**，把 **一次性连接码** 粘贴到远程页面中。
3. 电脑上的 **等待批准的设备** 中会出现该手机的设备指纹和请求的权限，核对后点击 **批准配对**；不认识的请求点击 **作废二维码**。

用同一账号从网页发起连接时，电脑会弹出“网页请求连接这台客户端”，选择 **允许连接** 或 **拒绝**。

### 手机能做什么

- 查看项目状态、任务时间线和审查结论；
- 切换当前项目、新建对话、切换模型；
- 发送消息、实时查看回复、停止回复、回答助手的提问。

手机 **不能** 访问文件、终端、设置、权限确认和邮箱。使用期间电脑端的 SomniQ Studio 必须保持运行和联网。

### 管理设备

- **已连接设备** 列表显示每台设备的状态、系统、设备指纹、允许的操作、配对时间和最近连接时间。
- **撤销**：立即终止该设备的访问。
- **重命名** 本机、**停用远程控制**。
- **重置身份并重新配对**：作废所有已配对设备。

### 连接另一台电脑

在 **远程控制** 中选择 **使用连接码加入设备**，粘贴另一台电脑生成的连接码并 **连接**。配对后：

- 对话侧栏顶部的 **运行位置** 可以选择在远程电脑上运行对话；
- 代码页的 **算力面板** 可以把计算任务发到远程电脑。

被连接的电脑需要在 **本机能力** 标签中打开 **接受可信设备的远程代码任务**、**允许可信设备与本机 Agent 对话**，并设置 **最大并行任务**。

**本机能力** 中还有图片互助相关的选项：

- **为其他用户生成图片**（默认关闭）：开启后，**未与你配对的其他用户** 发来的出图请求会自动在你的电脑上执行，直到你关闭为止。它使用你本机的 ChatGPT 账号，会消耗你的额度，并保留相应的聊天记录。请确认能接受后再开启。
- **出图时请求其他用户帮忙**：优先请求在线的互助用户帮你出图，无人在线时回退到本机账号。
- **在线的互助用户**：查看互助用户的忙闲状态（默认匿名）。
