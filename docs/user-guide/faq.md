# 常见问题

> 适用版本：SomniQ Studio v0.4.86 · [返回目录](README.md)

## 安装与启动

**Windows 提示“Windows 已保护你的电脑”，无法安装。**
安装包暂未使用商业代码签名证书。确认安装包来自 GitHub Releases 或官网后，点击 **更多信息 → 仍要运行**。见 [安装教程](installation.md#3-在-windows-上安装)。

**Windows 上打开应用后窗口一片空白。**
通常是 WebView2 Runtime 缺失或损坏。安装程序会自动安装 WebView2，但安装时如果没有联网会失败。请联网后重新运行安装包，或从微软官网下载安装“Microsoft Edge WebView2 Runtime”。

**macOS 提示“无法打开”或“无法验证开发者”。**
应用尚未经过 Apple 公证。到 **系统设置 → 隐私与安全性** 中点击 **仍要打开**；macOS 14 及以下也可以按住 Control 点按应用，选择 **打开**。见 [安装教程](installation.md#4-在-macos-上安装)。

**macOS 提示“已损坏，无法打开”。**
确认安装包来自官方渠道后，按 [安装教程 · 在 macOS 上安装](installation.md#4-在-macos-上安装) 中“已损坏，无法打开”的方法处理。

**macOS 每次升级后都要重新允许访问“文稿”“桌面”等文件夹。**
这是当前签名方式下的预期行为：授权在重启后保留，但在升级到新版本后需要重新授予一次。

## 账号与登录

**可以用自己的 OpenAI / Anthropic / DeepSeek API Key 吗？**
当前版本不支持。所有模型调用都通过 SomniQ 账号完成，额度与会员档位绑定。见 [账号、会员与模型](account-and-models.md)。

**注册页提示“人机验证服务由 Cloudflare 提供支持”，无法注册。**
服务器开启了人机验证，桌面端无法完成。点击 **打开网页版注册**，在浏览器中注册后回到应用登录。

**登录页提示“此安装包未配置可用的 HTTPS 托管账号服务器”。**
安装包不完整或不是官方版本。请从 GitHub Releases 或官网重新下载安装。

**应用顶部出现“当前版本已停止服务”。**
客户端版本过旧，已被服务端拒绝。点击 **立即更新**；如果更新失败，点击 **前往官网下载** 手动安装最新版。

**使用中突然回到了登录页。**
登录状态失效（例如在其他地方修改了密码）。重新登录即可，本地的项目、对话和文献库不受影响。

**付款后会员没有生效。**
回到应用点击 **刷新账户**。“收银台已打开”不代表付款成功，请以刷新后的账户状态为准。不要在状态未确认前重复下单；收银台被关掉时，用 **重新打开当前收银台** 继续同一笔订单。

## 模型与对话

**模型下拉列表是空的。**
确认已登录，然后在 **设置 → 模型服务** 中点击 **同步模型**。

**回复中显示“独立 Reviewer 当前不可用”。**
审查模型与执行模型是同一个，或没有选择审查模型。在 **设置 → 模型服务** 中把 **Reviewer 模型** 换成与执行模型不同的模型。

**开了 Reviewer 模型，但从来没有触发审查。**
独立审查默认关闭。请在对话页的 **项目摘要** 中打开 **自动审核** 开关。另外，纯问答式的回复（没有改文件、跑命令或检索等实质性工作）不会触发审查。见 [对话 · 独立审查](chat.md#9-独立审查)。

**长时间显示“等待模型响应”。**
高思考强度下模型可能在深度推理，超过 60 秒会有提示。可以继续等待，也可以 **停止回复** 后降低 **思考强度** 再点 **继续**。

**AI 没问我就改了文件或执行了命令。**
默认权限模式是 **自动批准**。如需逐项确认，把输入框下方的权限模式切换为 **询问** 或 **接受编辑**。已发生的文件修改可以在该轮回复末尾的“已编辑 N 个文件”卡片中 **撤销**。

**怎么搜索以前的对话？**
侧栏没有搜索框，请在对话中输入 `/session search <关键词>`。

**对话越来越慢或提示上下文接近上限。**
应用会在达到阈值时自动压缩上下文；也可以手动输入 `/compact`。如果话题已经转换，新建一个对话效果更好。

## 文献

**提示“外部文献检索需要 Go 及以上会员”。**
免费版只能使用本地文献库。外部检索（包括研究流程中的检索）需要 Go 及以上会员。

**对话中“本地文献证据”总是“未找到证据”。**
文献库还没有建立全文索引。到 **文献 → 检索 → 本地检索** 中点击 **建立本地索引** 或 **增量更新全库**。

**“获取 PDF”提示没有已知的直接下载链接。**
该条目没有开放的 PDF 直链。可以手动 **上传本地 PDF**，或配置 Playwright 插件后使用 **Playwright MCP 获取 PDF**。

**外部发现中 Semantic Scholar 显示缺少凭据。**
当前版本中 Semantic Scholar 默认不可用，会被跳过；其他数据源不受影响，检索时可以取消勾选它。

**怎么从 Zotero 迁移？**
在 Zotero 中导出为 Zotero JSON，然后在 **文献 → 添加文献 → 导入文献库** 中导入。见 [文献](literature.md#1-添加文献)。

## LaTeX

**LaTeX 页面提示“尚未安装系统 LaTeX”。**
应用不内置 TeX 发行版，需要安装 TeX Live（macOS 为 MacTeX）。可以点击 **前往对话安装** 让助手协助。见 [LaTeX 写作](latex.md#1-准备-tex-live)。

**中文显示为空白或编译报错。**
加入 `\usepackage{ctex}`（或使用 `ctexart` 文档类），引擎保持“根据源码自动判断”或手动选 xelatex。

**双击 PDF 不能跳回源码。**
在 LaTeX 页面重新编译一次；修改源码后未重新编译时，跳转位置是近似的。仍然不行时，到 **设置 → 关于与环境 → 本地环境检查** 确认 LaTeX 显示为“可用”。

**无法保存或编译，提示有待审阅的修改。**
AI 或外部程序修改了文件，需要先在 **变更集** 中审阅并 **应用已审阅修改**。见 [LaTeX 写作](latex.md#6-审阅-ai-和外部修改)。

**编译一直卡住。**
默认最长编译时间为 10 分钟，可在 **编译选项** 中调整；也可以试试 **清除缓存并重新编译**。

## 代码与任务

**代码页显示“编辑器启动失败”。**
点击 **重试**。macOS 首次使用需要联网下载编辑器运行时，请检查网络或代理设置。

**笔记本无法运行。**
先确认文件夹已被编辑器 **信任**（受限模式下笔记本不能运行），再到 **设置 → 关于与环境 → 本地环境检查** 确认 Python 和 Jupyter 可用。

**待办任务启动失败，提示需要 Git 仓库。**
待办任务和定时任务都在 Git 工作树中运行。在对话输入框下方的 Git 按钮中选择 **初始化 Git 仓库**。

**定时任务没有按时运行。**
定时任务只在应用打开时运行，关闭期间错过的触发会在下次启动时补跑一次。上一次运行尚未结束时，本次触发会被跳过。新邮件触发只支持 IMAP 账户。

## 反馈问题

1. 在出问题的对话页顶部点击 **导出故障调试包**。
2. 到 [GitHub Issues](https://github.com/zhuyingqin/Aris/issues) 新建问题，说明系统版本、应用版本（**设置 → 关于与环境**）、复现步骤，并附上调试包。

> 调试包中可能包含对话内容和文件路径，上传前请检查是否含有不便公开的信息。
