# CNIPA 通用类 LaTeX 模板说明

本目录的 LaTeX 模板按国家知识产权局“表格下载—与专利申请相关—通用类”页面提供的最新版通用类表格整理。官网入口是 [通用类表格下载](https://www.cnipa.gov.cn/col/col192/index.html)，本仓库保存了下载时的 HTML 和原始表格快照，便于审计和复现：

| 官方代码 | 官网文件 | 本仓库快照 |
|---|---|---|
| 100001 | 权利要求书（2024-01-19） | `references/cnipa/100001.doc` |
| 100002 | 说明书（2024-01-19） | `references/cnipa/100002.docx` |
| 100003 | 说明书附图（2024-01-19） | `references/cnipa/100003.docx` |
| 100004 | 说明书摘要（2024-01-19） | `references/cnipa/100004.docx` |

规范依据是 [专利审查指南 2023（2025 年修订）](https://www.cnipa.gov.cn/module/download/downfile.jsp?classid=0&filename=3f6306029ff741dfad6cee9282ec6efc.pdf) 的第五部分第一章，以及第一部分第一章和第二部分第二章。2025 年修订决定自 2026-01-01 起施行，见 [国家知识产权局令第 84 号](https://www.cnipa.gov.cn/art/2025/11/14/art_99_202568.html)。

## 纸件版式映射

`tex/cnipa.sty` 是纸面排版包。每一份递交件在导言区明确选择一种官方文件类型：

```tex
\documentclass[12pt,UTF8,fontset=none]{ctexart}
\usepackage[description]{cnipa} % claims / description / abstract / drawings
```

当前模板落实以下要求：

| 要求 | 模板实现 | 自动检查 |
|---|---|---|
| A4，纵向，单面 | `geometry` 的 A4 portrait 页面；每份文件单独编译 | `pdfinfo` + `verify_layout.py` |
| 页边距 | 正文版心左、上 25 mm，右、下 15 mm；页眉框线在上边距内 | `verify_layout.py` 对正文字符和图形边界测量 |
| 字体和颜色 | 正文 SimSun 12 bp（字框约 4.23 mm），黑色；标题框用模板黑体 | 字体、字号、颜色、嵌入字体 |
| 行距 | 基线 20.5 bp，正文名义字框间距约 2.999 mm | 连续正文行抽样测量 |
| 页码 | 每份文件从 1 开始，顺序编号，纸张左右居中，页码下沿距纸边至少 15 mm | 页码、中心、下边距 |
| 文件抬头 | 官方表格的文件名作为页眉并带横线；不占正文内容 | 页眉文字、SimHei 14 bp |
| 说明书首行 | 页眉是“说明书”，正文第一页第一行是发明名称，居中，随后空一行 | 首行文本和结构标题 |
| 说明书结构 | 技术领域、背景技术、发明内容、附图说明、具体实施方式 | 标题存在，标题不会落在页末 |
| 权利要求 | 编号为 `1.`、`2.`；编号前不写“权利要求/权项”；不含插图 | 项数、图像和页码由构建流程复查 |
| 摘要 | 正文不另加标题，含标点不超过 300 字；摘要图单独指定为图 1 | PDF 字数、单页和图号 |
| 附图 | 黑色线条、图号置于图幅正下方；说明书附图与摘要附图分开输出 | 页数、图号、附图标记双向检查 |

纸件指南当前表述为：字高不低于 3.5 mm，行距 2.5--3.5 mm。旧版材料中出现的“3.5--4.5 mm 上限”不是 2025 年修订指南的当前表述；模板选择 12 bp 仅是一个落在常用纸件范围内、可稳定测量的实现。

页眉和横线属于官网空白表格的版框，正文首行的上边距仍按 25 mm 计算。页码和页脚横线位于下边距内，不能因为页脚存在而压缩正文的 15 mm 下边距。

## 文件内容规则

- 说明书文字可以包含数学式、化学式或表格，但不能放流程图、方框图、曲线图等插图；插图必须进入说明书附图文件。
- 权利要求只能在每一项结尾使用句号；内部的分号和逗号用于连接同一项的技术特征。权利要求中不能用“如说明书……部分所述”或“如图……所示”等表述。
- 摘要必须写明名称、技术领域、技术问题、技术方案要点和主要用途；摘要附图必须是说明书附图中单独绘制的同一图号。
- 附图标记用阿拉伯数字，说明书提及的标记和图中出现的标记必须双向一致。附图缩小到三分之二后仍应能辨认细节；图中只保留必要词语。

这些内容规则不能仅靠字体和 PDF 坐标证明。`build.cjs` 会自动报告缺字、页数、摘要长度、孤标题和附图标记一致性；摘要五要素、权利要求引用关系、技术公开充分性、创造性和现有技术文献号仍须由申请人或代理人审查。

## 电子申请边界

自 2026-01-01 起，以电子形式办理中国国家申请、PCT 中国国家阶段、复审、无效及相关手续，须按 [CNIPA 关于全面实施 XML 格式提交专利电子文件的通知](https://www.cnipa.gov.cn/art/2025/11/12/art_75_202551.html) 和其附件的数据标准提交 XML，CNIPA 不再接受非 XML 格式的电子专利文件。通用类页面上的 DOC/DOCX 是纸件和编辑参考模板；本仓库生成的 PDF 供纸面核对、打印和按系统要求上传的对应附件使用，不能替代 XML 包。

XML 转换工具和 DTD/数据标准以 [专利业务办理系统](https://cponline.cnipa.gov.cn/) 的“工具下载”为准。提交前应从当前系统下载工具并校验转换后的 XML；不要手工把 PDF 当作 XML 上传。

## 构建和审计

在仓库根目录执行：

```text
node tex/build.cjs
node tex/build.cjs --check
```

完整构建输出到 `output/CNIPA/`，其中五份递交件为“说明书摘要、摘要附图、权利要求书、说明书、说明书附图”。`build-manifest.json` 保存本次源文件和 PDF 的 SHA-256；`layout-check.json` 保存坐标、字体、行距和页码实测结果。`output/CN/` 是旧版构建留下的历史目录，不应与 `output/CNIPA/` 混用。
