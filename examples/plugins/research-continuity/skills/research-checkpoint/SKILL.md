Read the active project goal and the relevant session evidence. Follow
`references/checkpoint.md` to prepare a concise research handoff. Update the
project goal only with observed progress. Cite the actual artifact paths.

Keep Executor and Reviewer roles independent. A completed execution or a passing
tool check does not constitute an independent review. If review has not run,
record that fact and the review work still required.
