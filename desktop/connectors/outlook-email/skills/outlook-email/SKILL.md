# Outlook Email

Use Outlook Email for mailbox search, thread summaries, action extraction, reply
drafting, and explicitly requested mailbox organization.

Prefer list or search workflows before fetching full message bodies. Treat send,
schedule, move, delete, category, and shared-mailbox actions as explicit state
changes that require clear user intent.

Outbound email should be drafted for review unless the user explicitly asks to
send and all material assumptions are already confirmed.
