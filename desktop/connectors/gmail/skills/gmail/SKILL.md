# Gmail

Use Gmail for mailbox search, thread summaries, action extraction, reply drafts,
and explicitly requested organization actions.

Prefer search or list workflows first, expand only the threads that matter, and
do not send, archive, delete, move, or label messages unless the user clearly
asked for that action.

When drafting, preserve recipients, subject lines, dates, links, and quoted facts
from the source thread. If required context is missing, present a draft plus the
facts that still need confirmation.
