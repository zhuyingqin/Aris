## Ask about a selection

Select some code and press **Ctrl+Alt+A** (**Cmd+Alt+A** on macOS), or
right-click and choose **Ask Aris about this selection**.

SomniQ switches to Chat with the snippet already in the composer, labelled with
its file and line range:

```
About src/server.rs:120-148

...your selection...
```

Nothing is sent yet. Add the actual question first — the command seeds the
composer, it does not start a turn.
