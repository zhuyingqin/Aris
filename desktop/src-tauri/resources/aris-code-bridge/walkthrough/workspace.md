## One project, two surfaces

The folder open here is the SomniQ project you picked in the app — the same
tree the assistant reads and writes.

- Files the assistant edits appear here as soon as they land on disk.
- Files you save here are recorded in the same change history, so an edit you
  made by hand can be reviewed and rolled back alongside the assistant's.
- Switching projects in SomniQ reopens this editor on the new folder.

The integrated terminal and any extension you install run as you, with your
permissions — they are not limited by the permission level set for chat.
