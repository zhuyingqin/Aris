## Notebooks

The Python and Jupyter extensions are installed on first launch, so `.ipynb`
files open in the full notebook editor with the variable explorer, plot viewer
and cell debugging.

**One thing worth knowing:** cells you run here use this editor's kernel, and
the assistant's notebook tools start their own. A variable you defined by
running a cell yourself is not visible to the assistant, and the reverse is
also true. If you ask it to carry on from state you created interactively, tell
it to re-run the cells that produce that state.
